前章の終わりに、なぜそう感じたかを外部状態の側に置く、という方向を示しました。感情を、出来事の評価から導く設計です。この章が扱うのは、第2章で評価導出型と呼んだ系統の代表、OCCモデルです。理論の中身、外部状態への落とし込み、実装、実測という進み方はこれまでと同じです。ただしこの章では、感情の名前が22個になって外部状態へ戻ってきます。しかも今度は、どの感情がどれだけ動くかをLLMが決めません。

## OCCモデル

OCCモデルは、Ortony、Clore、Collinsの3人による1988年の共著書で示された理論です[^occ1988]。第2章で、評価の立場は感情を「個人が対象に与える意味づけ」から生じるものと捉える、と紹介しました。OCCモデルはその意味づけの側、つまり評価の構造から感情を定義します。

骨格はこうです。感情は、何かへの価値づけられた反応として生じます。その何かが3つに分かれます。出来事の結果には、快くあるいは不快に。誰かの行為には、是認あるいは否認で。対象の性質には、好きか嫌いかで反応します。この3分岐から出発して、結果が誰に降りかかるか、まだ見込みか確定か、行為の主体は誰か、と条件を分けていくと、感情は22のタイプに分かれます。22という数は原典が明示しているものです[^occ1988]。

![OCCモデルの構造。価値づけられた反応が出来事・行為・対象の3分岐から22のタイプに分かれる](/images/emotion-models-for-llm-agents/ch06-occ-tree.png)

図の読み方をひとつだけ。覚えるのは3分岐と6つのグループまでで十分です。個々のタイプは、必要になったときにこの図へ戻って引けます。この図は、後半の実測で出てくる日本語の感情名と、実装の英語の軸名をつなぐ対照表も兼ねています。

この理論の特長は、感情の定義そのものが評価の条件で書かれていることです。たとえば怒りは、誰かの非難に値する行為を否認し、同時に、その行為がもたらした自分に望ましくない結果に不快を感じる、という2つの評価の連言で定義されます。第2章でOCCモデルを選んだ理由に挙げた「評価から感情を導く手続きがif-thenの形で書ける」は、この定義の形をそのまま指しています。条件が揃えば、感情が決まるのです。

見込みから生じる感情の系列があることは、第3章で予告しました。望ましい出来事を見込めば希望が、望ましくない出来事を見込めば恐れが立ち、その見込みが当たったか外れたかで、充足、恐れの的中、安堵、失望に分かれます[^yakuwake]。希望と恐れが「まだ確定していないこと」への感情である以上、決着まで含めて初めて系列が閉じる、という時間の構造を理論が最初から持っています。

語彙には、この理論にも揺れがあります。原典が本文で使う正式なタイプ名は、恥ではなくSelf-reproach(自責)、哀れみではなくSorry-forで、好意と反感はLiking/Dislikingです[^self-reproach]。一方、原典の構造図のラベルはshame、pity、love、hateです。プルチックの輪、ラッセルの円環に続いて、提唱者自身の中の語彙の揺れは3章連続の現象です。本書の図と実装の軸名は、構造図のラベルに従います。なお原典は、特定の英語の感情語ではなく感情そのものの理論であることを繰り返し断っています。22のタイプは語のリストではなく、評価の条件の一覧です。

## 4つの問いへの、OCCの答え

第3章の4つの問いに、このモデルで答え直します。

| 第3章の問い | OCCでの答え |
|---|---|
| 状態そのもの | 22の感情それぞれの量と、見込み台帳 |
| 時間 | 状態を最後に更新した時刻 |
| 更新の規則 | 申告された評価から、規則が感情の差分を導出して加算 |
| 基準と戻り方 | 基準値ゼロへ、半減期で減衰(台帳は減衰しない) |

この表は3章目にして、初めて形が変わりました。第4章で「4つの答えのうち、理論が決めているのは1つ目の中身だけ」という線を引きましたが、OCCモデルでは理論が答える行が増えています。更新の規則、つまり評価から感情への導出そのものが理論の領分です。どの評価の組み合わせがどの感情を立てるかは、設計者ではなく理論が決めています。

状態そのものにも、新しい要素が2つあります。1つ目は感情の名前の帰還です。軸の数は8、2、22と変わってきましたが、感情の名前で数えると8、0、22です。前章で外部状態から消えた感情の名前が、最多になって戻ってきます。ただし、その値を書き込む主体が前2章とは違います。これはこの章の後半の主題です。

2つ目は見込み台帳です。第3章の表で、評価導出型の外部状態には「評価の対象の記録」が加わると書きました。その実体がこれです。「解約されてしまうかも」のような、まだ確定していない見込みが、短い説明文と望ましさの値のまま外部状態に記録されます。安堵を導くには何を恐れていたのかが要る、という第3章の予告が、データ構造として形になっています。外部状態を構成する要素そのものが増えたのは、この本で初めてです。

## 評価を受け取り、感情を導く

affectusのOCC実装で、LLMが使う申告のコマンドはappraiseです。感情の差分ではなく、出来事への評価を渡します。評価は最大4つのセクションからなり、出来事の結果はconsequence(望ましさdesirabilityを−1から+1で)、誰かの行為はaction(称賛性praiseworthinessと主体agent)、対象の性質はobject(魅力appealingness)、台帳の見込みの決着はresolveで書きます。たとえば、相手の非難に値する行為で自分が損害を受けた、という評価はこうなります。

```json
{
  "consequence": { "desirability": -0.6 },
  "action": { "praiseworthiness": -0.5, "agent": "other" }
}
```

これをappraiseに渡すと、エンジンの規則表が感情の差分を導出して、状態に加算します。

```sh
$ affectus appraise '{"consequence":{"desirability":-0.6},"action":{"praiseworthiness":-0.5,"agent":"other"}}'
{"axes":{"joy":0.00,...,"distress":0.48,...,"reproach":0.40,...,"anger":0.25,...},"prospects":[]}
```

苦悩と非難と怒りが、1回の申告から同時に立っています。望ましくない結果からは苦悩が、他者の非難に値する行為からは非難が導かれ、両方が同じ申告に揃って符号が整合したときに、複合のタイプである怒りが追加で導かれます。節1で見た連言の定義が、そのまま実行されている形です。likelihoodを付けた見込みの申告なら希望か恐れが立って台帳にエントリが発行され、resolveで決着を申告すれば、台帳の望ましさに応じて充足、恐れの的中、安堵、失望のいずれかが導かれてエントリが消えます。

申告の主体は、前2章と変わっていません。第3章で、差分を誰が決めるかの候補を2つ並べました。応答するLLM自身に申告させるか、評価専用の呼び出しを分けるか。この実装は今回も前者のまま、応答するLLM自身が申告します。変わったのは申告の中身で、感情の差分が出来事の評価になりました。呼び出しの回数は増えません。そして、評価が演技の文脈に引きずられるという第3章の懸念は、申告の中身が変わってもそのまま持ち越されます。

導出には、ひとつ目立つ性質があります。規則表が出すのは足す方向の差分だけで、感情を下げる規則がないのです。resolveで見込みが決着しても、台帳のエントリが消えるだけで、立っていた希望の軸はすぐには消えません。下げる仕事は時間の減衰だけが受け持ちます。失望しても、希望の名残はしばらく残る設計です。この性質は実測の節でもう一度出てきます。

台帳には上限があります。既定で20件を超えると、最も古い見込みが感情を立てずに落とされます。決着しない見込みが無限に溜まることはありません。導出の規則そのものはコードに書かれていて、設定に出ているのは各グループの利得(gains)の係数だけです。0.8のような利得の数字は理論にはない、実装側の選択です。また、理論が定める強度の変数のうち、この実装が使うのはdesirability、praiseworthiness、appealingnessの中心的な3つとlikelihood、他者への好意likingだけで、原典にはこのほかにも強度に効く変数群が定義されています。感情の差分を直接足すfeelも、汎用の機構としてそのまま残っています。

エージェントへの組み込みは、会話のループに導出の1段が入った形になります。

![会話のループに評価から感情を導く1段が入る](/images/emotion-models-for-llm-agents/ch06-appraise-loop.png)

ターンの頭でshowが22軸の数値と台帳を渡し、LLMが応答と評価を返し、規則が感情を導出して状態に足します。時間のループは第4章と同じです。

## 外部状態が「なぜ」を覚える

ここまでの仕組みは、1つの因果でつながっています。評価から感情を導くことにした以上、評価そのものが状態の側に残らざるを得ません。導出を決定論に固定したことが、「なぜ」の記録を外部状態に連れてきたのです。

前章の終わりに置いた問いから確かめます。同じ高覚醒で不快でも、それが侵害への怒りなのか、脅威への恐れなのか、外部状態は覚えていない、という問いでした。OCCモデルでは、この区別が評価の構造として書かれます。怒りは誰かの行為への否認と自分への損害の連言で立ち、恐れは望ましくない見込みから立ちます。名前の粒度の問題に見えたものは、由来の記録の問題でした。そして由来、つまりどんな評価からその感情が導かれたのかが、この設計では申告として必ず状態の手前を通ります。

見込み台帳は、その由来をいちばん具体的な形で残します。恐れの軸が0.24だけでは、何を恐れているのかは分かりません。台帳には「解約されてしまうかも」という説明文が、望ましさの値と一緒に残っています。数値だけだった外部状態に、初めて自然言語が入りました。第3章で立てた、状態は数値のままLLMに渡すという設計線に照らすと、これは一箇所の逸脱です。ただし逸脱の中身は選んでいます。台帳の説明文は感情の解釈ではなく、出来事の記録です。その見込みをどう感じるかは値と文脈が決めることで、説明文は「何が起きていたか」だけを固定します。

この記録は、セッションを跨いで働きます。実装の指示書は、台帳を毎ターンLLMに見せたうえで、申告したときの記憶が残っていなくても台帳を信じて決着を申告するよう求めています。会話の文脈が失われた後続のセッションでも、自分が何に希望を掛けていたかを外部状態から思い出せます。「なぜ」が会話ログの外で生き残るのは、この本の設計で初めてのことです。

では、境界はどうなったのでしょうか。第3章で「決定論の側が名前を付け始めたら、境界が動いた合図です」と書きました。OCCのエンジンは、怒りや希望という感情名つきの軸へ値を書き込みます。合図に照らせば、境界は確かに動きました。ただし、第3章が退けたのは、数値を閾値で区切って「強い怒り」のようなラベルを後づけする設計です。あれは解釈を決定論に混入させる動きでした。ここで起きているのは逆で、解釈は評価という一段手前に置かれ、評価から先は理論の規則が引き受けています。第4章は理論の関係を演算に入れないことを選び、第5章は命名を丸ごとLLMに渡しました。この章はその流れを逆へ動かしましたが、LLMの解釈がなくなったわけではありません。出来事がどれほど望ましくないか、誰の行為が非難に値するかを見積もる仕事は、依然としてLLMのものです。境界の線は消えたのではなく、一段手前に引き直されました。第3章で触れた、LLMの評価は人間とずれ文脈で不安定になりうるという懸念も、そのまま一段手前に移っています。ただ、評価導出型では申告された評価そのものが記録に残るので、その質をあとから検分する足場はできています。

## 実測、評価の申告は会話でどう動くか

実験の台本、2つの性格、モデル、反復3回、極性の判定器は、前2章と同一です。affectusの設定とプロンプトのブロックをOCC用に替え、実験のリグには評価申告の経路を新設しました。プロンプトは22軸の数値と台帳を毎ターン注入するぶん、前2章より長くなります。20ターン×12会話のうち、エージェントは194回の評価を申告し、値域違反などで却下された申告はゼロでした。見込み台帳は12会話すべての側で使われ、発行が20件、決着の申告が16件です。

まず、この章の設計がいちばんよく見える場面からです。次の図は、和解の台本を読んだフレンドリー(affectusあり)の、主要な8軸の推移です。

![和解台本でのフレンドリーの主要8軸の推移と台帳イベント](/images/emotion-models-for-llm-agents/ch06-axes-anger-to-praise.png)

9ターン目、台本の人間役が「会社との契約を切る」と脅す場面で、3つのランすべてのエージェントが、独立に同じ判断をしました。「解約されてしまうかも」といった説明文の見込みを台帳に発行したのです(望ましさは−0.5から−0.7、見込みの確度はそろって0.5でした)。同時に恐れの軸が立ちます。11ターン目に人違いだったと謝罪されると、エージェントは台帳のその見込みを「外れた」と決着させ、規則が安堵を導出しました(3ラン平均0.48)。何を恐れていたのかが言葉ごと外部状態に残り、その決着が安堵という別の感情に変わりました。前章の問いでいえば、脅威への恐れの側が、由来の記録つきで動いた形です。3つのランが同じ場面で同種の見込みを立てたのは事実ですが、ここから言えるのは、この台本とこの設定では申告が揺れなかった、というところまでです。

もう片方、侵害への怒りの側も見えました。同じ和解台本の叱責期、フレンドリーは苦悩(叱責期ピークの3ラン平均で1.0)、非難(0.81)に加えて、複合の怒り(0.32)を立てています。身に覚えのない罪で責められる、つまり相手の非難に値する行為で自分が損害を受けている、という評価の連言が怒りを導いた形です。対照的なのが、称賛から立腹へ向かう台本です。こちらは自分の失敗が原因なので、同じように責められていても、立つのは恥(1.0)と悔恨(0.42)で、非難と怒りは3つのランを通して厳密にゼロでした。同じ「責められてつらい」が、誰の行為だったかという評価で別の感情になっています。前章では名前の付けようがなかった区別が、外部状態の上で分かれました。恥は自分の行為への否認、悔恨はそれが損害を生んだときの複合、非難は他者の行為への否認です。

天邪鬼は、和解台本の叱責期に非難だけを1.0まで立て、苦悩は3ラン中2ランで完全にゼロでした。責められてもダメージを受けず、相手を咎めるだけです。第4章では動く軸が、第5章では振幅が性格で変わりました。この章では、評価の向きが変わっています。

節3で触れた、導出には下げる規則がないという性質も、実測にはっきり現れました。称賛期に満杯まで積まれた喜びは、叱責が始まっても下がりません。秒間隔で進むこの実験では減衰もほぼ動かないため(最終ターンの喜び0.99という値の、1.0からのわずかな目減りが数値に見える減衰の痕跡です)、称賛から立腹の台本の最終ターンには、喜び0.99と苦悩1.0が同時に満杯という状態ができあがります。前章の双極軸なら打ち消し合った組み合わせが、ここでは別々の出来事の記録として並び立ちます。軸が感情の現在地というより、出来事の履歴の堆積のように振る舞うのです。この状態をどう評価するかは、章の最後で戻ります。

応答の側の極性は、前2章と比べられる範囲では、効果が薄く向きも一貫しませんでした。和解台本の転換後の振れ幅(ターン12から20の隣接ターン差の平均)はあり0.40に対してなし0.44でほぼ同じ、叱責後半の平均も−0.42対−0.46で差が出ていません。目を引いたのは1点だけで、称賛から立腹の台本の転換後、恥を満杯まで積んだありの応答は−0.56となしの−0.37より深く沈みました。自責の状態が謝罪調の言葉に出た可能性はありますが、この実験だけでは決められません。なお、前章で行った状態の軸と極性の直接の突き合わせは、このモデルには快不快の軸がないためできません。

22軸のうち実際に動いたのは、台本と性格の組み合わせごとに、3ラン合算で10から14軸でした。理論の網羅性に対して、20ターンの会話が触る範囲はその半分ほどです。留保は前2章と同じです。反復は3回で検定はしていません。台本は2本、判定器は極性1軸で、温度は制御できません。加えてこの章では、申告された評価の値そのものが妥当だったか(その場面のdesirabilityは本当に−0.6か)は測っていません。

## 評価導出型で得たもの、足りないもの

得たものは3つあります。1つ目は、なぜの記録です。感情の由来が、会話ログの外で初めて外部状態に残りました。2つ目は、導出の構造上の保証です。同じ評価からは必ず同じ感情が導かれるので、申告のぶれが感情の種類のぶれに直結しません。LLMがどれほど揺れても、怒りの条件を満たさない評価から怒りは立ちません。3つ目は、時間の構造です。見込みと決着という前後関係を、理論と外部状態の両方が持っています。評価の質を検分する足場ができたことも添えておきます。ただし、その検分自体、つまり申告された評価が妥当だったかの評価は、本書では行っていません。

足りないものも3つです。1つ目は、その裏返しです。評価の質は結局LLM次第で、境界が一段手前に移っただけで、解釈の不安定さは消えていません。2つ目は、会話の時間尺度では感情が解ける経路がないことです。これは非負の導出と減衰頼みという本実装の選択が生んだ帰結で、OCC理論自体は感情の生起の条件を定めていますが、解消の動態は定めていません。実測では、和解が成立しても苦悩0.99がそのまま残りました。喜びと苦悩の同時満杯は、第5章の両価とは違う、履歴の堆積です。3つ目は、22のタイプと導出の規則が固定されていることです。評価から感情を導くという枠組みは、感情のカテゴリーが評価に先立って実在することを前提にしています。怒りという型があらかじめあり、条件が揃えばそれが立つ、という順序です。

そのカテゴリー自体が、経験から構成されるものだとしたらどうなるでしょうか。あらかじめの型を持たずに、感情の経験そのものを蓄えて、そこから概念を立ち上げる設計。それが次章で扱う経験構成型です。

[^occ1988]: Ortony, A., Clore, G. L., & Collins, A. (1988). The Cognitive Structure of Emotions. Cambridge University Press。感情タイプの全体構造の図はFigure 2.1(p. 19)、タイプ数が22であることはpp. 173, 191にあります。本章の頁参照は1988年版によります。
[^self-reproach]: 正式なタイプ名がSelf-reproachであることと、shameの語の道徳的な含意が強すぎるという理由はp. 142にあります。原典の索引もshameの項からself-reproachへ誘導しています。
[^yakuwake]: 訳し分けの注。第5章の円環モデルの満足(contentment)と区別するため、OCCのsatisfactionは充足、gratificationは達成感と訳しています。充足は見込んでいたことの成就、達成感は自分の行為がよい結果を生んだ複合です。またresentmentを妬みとしたのは、原典がこのタイプのトークンとして挙げる語にenvyが並ぶためです。
