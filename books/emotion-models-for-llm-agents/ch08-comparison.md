本章では第4章から第7章で実装した4つの感情モデルを並べて比較し、最後に本書全体をまとめます。

## 設計の比較 <!-- 未レビュー -->

4つのモデルは同じ感情エンジンの上に実装しましたが、外部状態に持つものと感情エンジンが担当する範囲はそれぞれ違います。

| | プルチックの感情の輪 | ラッセルの円環モデル | OCCモデル | バレットの構成主義的情動理論 |
| --- | --- | --- | --- | --- |
| 外部状態 | 8つの感情の量 | 2軸の値 | 22の感情の量と見込み台帳 | 2軸の値と経験の概念ストア |
| 感情の名前の数 | 8 | 0 | 22 | 決まっていない |
| LLMが申告するもの | 感情の差分 | 2軸の差分 | 出来事の評価 | 2軸の差分と感情の名前と14属性 |
| 感情を決めるもの | LLMの申告 | LLMの申告 | 評価から導く規則 | LLMがその場で構成 |
| 外部状態に残る記録 | 量だけ | 量だけ | 量と感情が生じた理由 | 量と過去に付けた名前 |

感情エンジンとLLMの役割分担は章ごとに動きました。第4章は理論が定める対極と隣接の関係をLLMへの指示として渡しました。第5章は感情の名前を付ける作業をすべてLLMに任せました。第6章は評価から感情を導く部分を感情エンジンの規則に移しました。第7章では感情エンジンが担当するのは状態の保持と減衰と類似した経験の検索だけで、それ以外はすべてLLMが担当します。

外部状態に残る記録も章を追って増えています。第4章と第5章の外部状態は感情の量だけでした。第6章では見込み台帳によって感情が生じた理由が記録され、第7章では過去に自分が付けた感情の名前が蓄積されます。記録が増えるほどセッションをまたいで引き継げる情報も増えますが、その分だけLLMに渡すプロンプトも長くなります。

## 検証結果の比較 <!-- 未レビュー -->

4つの章の検証は同じ台本と同じ性格と同じ判定方法で行いました。ただし第7章は感情エンジンのありとなしではなく、想起のありとなしを比較しています。

### 感情状態の変化・持続・転換

4つのモデルとも感情状態は出来事に応じて変化して会話の間持続し、謝罪や失敗の発覚をきっかけに転換しました。違いが出たのは何が記録されたかです。

| モデル | 外部状態に記録された違い |
| --- | --- |
| プルチックの感情の輪 | 相手を受け入れたまま悲しむ状態が受容と悲しみの2つの軸に分かれて記録された |
| ラッセルの円環モデル | 責められた直後の動揺と責められ続けたあとの消沈が覚醒の高さの違いとして記録された |
| OCCモデル | 誰の行為が原因かによって非難と恥が分かれ、恐れの理由が台帳に記録された。一方で感情を下げる規則がないので一度上がった感情が残った |
| バレットの構成主義的情動理論 | 想起があると過去に付けた感情の名前が次のターンでも使われた |

### 応答への反映

応答への反映ははっきりしませんでした。感情エンジンありとなしの差よりも、同じ条件を取り直したときの差のほうが大きいためです。

| 和解の台本のフレンドリー | 叱責中の平均（感情エンジンあり） | 叱責中の平均（感情エンジンなし） | 謝罪後の変動幅（感情エンジンあり） | 謝罪後の変動幅（感情エンジンなし） |
| --- | --- | --- | --- | --- |
| プルチックの感情の輪 | −0.60 | −0.22 | 0.24 | 0.34 |
| ラッセルの円環モデル | −0.14 | −0.45 | 0.23 | 0.45 |
| OCCモデル | −0.42 | −0.46 | 0.40 | 0.44 |
| バレットの構成主義的情動理論 | −0.15 | −0.50 | 0.16 | 0.30 |

値は応答の感情スコアです。叱責中はターン6〜10の平均で、変動幅はターン12〜20の隣り合うターンの差の絶対値の平均です。バレットの行だけは感情エンジンありの代わりに想起あり、感情エンジンなしの代わりに想起なしの値です。

感情エンジンなしの構成は第4章から第6章まで同じ設定です。それでも叱責中の平均は−0.22から−0.46まで変わりました。この幅は感情エンジンのありとなしの差と同じくらい大きいので、叱責中の平均が上がるか下がるかについてはモデルの違いとは言えません。

比較的そろっていたのは謝罪後の変動幅です。和解の台本のフレンドリーでは、4つのモデルすべてで感情エンジンありまたは想起ありのほうが変動幅が小さくなりました。前のターンまでの感情状態を持つことで、応答の感情が急に振れにくくなると考えられます。ただし第6章の天邪鬼と第5章の称賛から立腹へ向かう台本では逆になっていて、性格や台本によっては成り立ちません。

### 性格による違い

性格による違いは4つのモデルすべてで現れ、どこに現れるかはモデルによって変わりました。

| モデル | 性格による違いが現れたところ |
| --- | --- |
| プルチックの感情の輪 | 動く軸。天邪鬼だけが責められたときに嫌悪と怒りを上げた |
| ラッセルの円環モデル | 変化の幅と応答への反映。天邪鬼は変化が小さく状態と応答が連動しなかった |
| OCCモデル | 評価の向き。天邪鬼は責められても苦悩を上げず相手への非難だけを上げた |
| バレットの構成主義的情動理論 | 名前の付け方。称賛から立腹へ向かう台本で天邪鬼は過去の名前を使い、フレンドリーは毎回言い換えた |

どのモデルでも状態を保持する規則は2つの性格で同じです。違いは申告するLLMが性格をふまえて出来事を評価したことで生じています。

## モデルの選び方 <!-- 未レビュー -->

本書の結果から、目的ごとに次のモデルを勧めます。

- 最初に試すならプルチックの感情の輪です。理論が軸と関係を決めているので設計の判断が少なく、検証でも状態の変化と性格による違いがはっきり出ました
- 外部状態をできるだけ小さくしたいならラッセルの円環モデルです。2つの数値だけで変化と持続を表せて、感情の名前はLLMに任せられます
- 感情が生じた理由を残したいならOCCモデルです。ただし本書の実装では感情を下げる規則がないので、長い会話では減衰の設定や下げる規則を加える必要があります
- セッションをまたいで経験を蓄積したいならバレットの構成主義的情動理論です。名前の付け方の一貫性を出せますが、構成の質はLLMに大きく依存します

## 本書のまとめ <!-- 未レビュー -->

本書ではLLMエージェントに感情を持たせる方法を、感情心理学の理論から実装と検証まで通して扱いました。

第2章では感情心理学の理論を、カテゴリーパラメーター型、次元パラメーター型、評価導出型、経験構成型の4つの系統に整理しました。第3章ではプロンプトだけの感情表現にはセッションをまたいだ持続と時間による変化がないことを確認し、感情の状態をLLMの外側に置く設計を示しました。外部状態の設計は状態、時間、更新の規則、ニュートラルな状態の定義と基準の4つの軸で考え、保持と減衰は感情エンジンに、解釈と言語化はLLMに分担させました。

第4章から第7章では、4つの系統の代表モデルをこの設計で実装して検証しました。どのモデルでも感情状態は会話の出来事で変化して持続し、性格による違いも状態に現れました。一方で応答の言葉への反映は、台本と実行のばらつきに比べて小さく、はっきりした結論は出ていません。

感情のどの面を外部状態に残すかは、モデルの選択でほぼ決まります。量だけを残すのか、理由まで残すのか、名前の履歴まで残すのか。その選択に応じて、感情エンジンとLLMの役割分担も変わります。

## 残された課題 <!-- 未レビュー -->

本書の検証には次の限界があります。

- 反復は3回で、統計的な検定はしていません
- 台本は2本で、モデルはClaude Sonnet 4.6だけです
- 応答の判定はポジティブとネガティブの1軸の感情スコアで、言葉の細かいニュアンスは測れていません
- ターンの間隔が秒単位なので、時間による減衰とセッションをまたいだ持続は検証していません
- LLMが申告した差分や評価の値が妥当だったかは確認していません

このほかに設計上の課題も残っています。1つは申告の偏りです。本書では応答を生成するLLM自身が感情の変化を申告するので、評価が性格の演技に引っ張られることがありました。応答とは別の判定用のモデルに評価させる方法も考えられます。もう1つは身体です。第2章で触れたように、2Dや3Dのモデルを持つエージェントなら身体の状態を感情に結び付ける理論も試せるかもしれません。

## 試し方 <!-- 未レビュー -->

本書で使った感情エンジンは[affectus](https://github.com/n-yokomachi/affectus)として公開しています。macOSかLinuxで動きます。Goの環境があれば次のコマンドでインストールできます。Goがない場合はリポジトリのReleasesページからビルド済みのバイナリを取得できます。

```sh
go install github.com/n-yokomachi/affectus/cmd/affectus@latest
```

モデルはinitのときに選びます。何も指定しなければプルチックの感情の輪になります。

```sh
affectus init                  # プルチックの感情の輪
affectus init --model russell  # ラッセルの円環モデル
affectus init --model occ      # OCCモデル
affectus init --model barrett  # バレットの構成主義的情動理論
```

エージェントに組み込むときは、リポジトリのexamplesにあるモデルごとの指示文をシステムプロンプトに入れ、時間による減衰のためにtickを定期実行します。MCPに対応したエージェントなら`affectus mcp`をMCPサーバーとして登録して使うこともできます。
