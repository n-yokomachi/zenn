本章では4系統のうち次元パラメーター型と呼んだ系統の代表モデルとしてラッセルの円環モデルを扱います。前章のプルチックの感情の輪は8つの感情の名前を軸として持っていましたが、円環モデルは感情の名前を持たず2つの軸だけで感情を表します。

## ラッセルの円環モデル <!-- 未レビュー -->

Russell（以降ラッセル）は1980年の論文で「感情の状態は2次元の双極空間の上の円として最もよく表される」と主張しました[^russell-thesis]。双極とは1本の軸の両端に反対の意味が来ることです。2つの軸は快-不快（pleasure-displeasure）と覚醒の程度（degree of arousal）で、現在一般にはvalenceとarousalと呼ばれています。valenceは後年に定着した呼び名で、1980年の原文には出てきません。

平面の上には8つの概念が45度おきに円環状に並びます。0度の快から反時計回りに、興奮、覚醒、苦悩、みじめさ、抑うつ（臨床の診断名ではありません）、眠気、満足です。
この8つの概念は基本感情ではなく、あくまで円環上の位置を示す目印です。ラッセルはこの円環を仮説として示したうえで、28個の感情語を被験者に判断させ、実際に語がこの順番で円に並ぶことを確かめています。
なおラッセルはのちに構成主義の立場へ移りましたが、本書が使うのは1980年の円環モデルです。

![ラッセルの円環モデル。快-不快と覚醒の2軸平面に8つの概念が円環をなして並ぶ](/images/emotion-models-for-llm-agents/ch05-circumplex.png)


## ラッセルの円環モデルを元にした4つの設計軸 <!-- 未レビュー -->

第3章の4つの設計軸は円環モデルでは次のようになります。

| 第3章の設計軸 | ラッセルでの設計 |
| --- | --- |
| 状態 | 2つの軸の値 |
| 時間 | 状態を最後に更新した時刻 |
| 更新の規則 | 出来事に応じた差分の加算 |
| ニュートラルな状態の定義と基準 | valenceは0へ、arousalは0.3へ、半減期で減衰 |

状態は2つの軸の値だけで、たとえばvalenceが0.4でarousalが0.55という形です。快-不快と覚醒は感情の名前ではないので、外部状態から感情の名前がなくなります。

ニュートラルな状態の基準値はvalenceが0でarousalが0.3です。何も起きていない落ち着いた状態にも少し覚醒が残る設計です。理論にあるのは「原点はおそらく順応水準ないし中立的な感情に対応する」という一文だけなので[^disk-origin]、0.3は実装上の判断で決めた値です。

## 感情エンジンの中身 <!-- 未レビュー -->

感情エンジンはプルチックと同じものを使い、設定ファイルだけを差し替えます。

```yaml:internal/engine/russell.default.yaml
version: 1
model: russell
clamp:       { min: -1.0, max: 1.0 }
delta_clamp: { min: -1.0, max: 1.0 }

axes:
  - { name: valence, baseline: 0.0, halflife_minutes: 90, range: { min: -1.0, max: 1.0 } }
  - { name: arousal, baseline: 0.3, halflife_minutes: 90, range: { min:  0.0, max: 1.0 } }

fragment_file: ""
```

前章の設定と比べると、軸が2本になってoppositeの宣言がなくなり、軸ごとの値域を指定するrangeが加わっています。oppositeがないのは、快と不快を1本の軸のプラス側とマイナス側として表すからです。rangeはvalenceを−1から+1に、arousalを0から1にしています。円環の縦軸は覚醒と眠気を対極に置いていますが、実装では眠気を覚醒が0の状態として扱いました。この軸ごとの値域は、ラッセルのモデルのためにエンジンへ追加した機能です。

操作は前章と同じshow・feel・tickの3つです。

```sh
$ affectus show
{"valence":0.00,"arousal":0.30}
$ affectus feel '{"valence":0.4,"arousal":0.25}'
{"valence":0.40,"arousal":0.55}
```

何も起きていない状態でもarousalは基準値の0.30で、feelで差分0.25を足すと0.55になります。

設定には円環の情報がありません。円環は状態が平面上にどう分布するかについての理論の主張で、個々の状態が守るべき制約ではないからです。論文自身も円について「円盤や車輪のほうがよいイメージだろう」と書いています[^disk-origin]。円環の情報はLLMへの指示文にだけ含まれます。指示文は象限ごとの例語を示したうえで「名前を付けるのはあなた」「意味は平面上の位置にだけ宿る」と伝えています[^snippet-russell]。快が高く覚醒も高い状態を高揚と呼ぶか歓喜と呼ぶかは、毎回LLMがコンテキストから判断します。

2軸にしたことで表せなくなったものもあります。嬉しさと寂しさが同居するほろ苦さのような対極の感情の両立は、1本の双極軸の上では打ち消し合って0付近の値になります。強い嬉しさと強い寂しさの同居と、どちらも感じていない状態を区別できません。これは「感情の空間は双極であり、反意語はおよそ180度離れて位置する」という理論どおりの結果です[^bipolar]。前章で受容と悲しみの2つの軸に分かれて記録された状態も、2軸では1つの点にまとめられます。

## 検証結果 <!-- 未レビュー -->

それではラッセルの円環モデルをベースとした感情モデルの検証結果を見ていきます。

### 感情状態の変化・持続・転換

2軸の状態も出来事に応じて変化して会話の間持続し、謝罪をきっかけに転換しました。さらに同じ否定的な出来事でも、覚醒の高さによって状態の動き方が2通りに分かれました。

![和解台本でのフレンドリーのvalence-arousal平面軌跡](/images/emotion-models-for-llm-agents/ch05-va-trajectory-anger-to-praise.png)

図は和解の台本をフレンドリー（感情エンジンあり）に読ませたときの2軸平面上の軌跡です。責められ始めた直後は覚醒が上がり、円環でいう苦悩の付近に来ました。叱責が続くと覚醒は下がり、10ターン目には3回の平均で(−0.65, 0.15)の抑うつの付近に移りました。11ターン目の謝罪で状態は快の側へ戻り、最終ターンには(+1.00, 0.62)になっています。

前章の8軸では悲しみが上がり続けるだけだった場面で、2軸では責められた直後の動揺と責められ続けたあとの消沈が覚醒の高さの違いとして記録されました。称賛から立腹へ向かう台本でも、失敗が発覚した直後に覚醒が上がり終盤は消沈に向かう同じ動きが見られました。円環の語は外部状態には書かれていませんが、このように結果を解釈する手がかりとして使えます。

### 応答への反映

状態が応答に反映されるかどうかは性格によって分かれました。称賛から立腹へ向かう台本ではフレンドリーの状態のvalenceと応答の感情スコアが連動し、天邪鬼では連動しませんでした。

円環モデルでは状態のvalenceと応答の感情スコアがどちらも快-不快を表す1軸なので、2つを直接比べられます。

![称賛から立腹の台本での状態のvalenceと応答の感情スコア。フレンドリーと天邪鬼の比較](/images/emotion-models-for-llm-agents/ch05-valence-vs-polarity-praise-to-anger.png)

図は称賛から立腹へ向かう台本での推移です。フレンドリー（左）は称賛の間はどちらも高く、失敗が発覚するとそろって下がりました。天邪鬼（右）は状態のvalenceが叱責で下がっても、応答の感情スコアは最初から皮肉を含んで上下しています。台本は2つの性格で同じなので、この差は状態と応答の間に性格による解釈が入っていることを示します。

| 状態のvalenceと応答の感情スコアの相関係数 | フレンドリー | 天邪鬼 |
| --- | --- | --- |
| 称賛から立腹へ向かう台本 | 0.66 | −0.02 |
| 和解の台本 | 0.66 | 0.41 |

相関係数は3回の実行の20ターンを合わせた60組で計算しています。和解の台本では天邪鬼でも相関が出たので、反映の度合いは台本によっても変わります。また比較している状態はそのターンの出来事を反映したあとの値なので、状態と応答が同じ出来事にそれぞれ反応した分も相関に含まれます。

前章と同じ指標でも比べました。

| フレンドリー | 感情エンジンあり | 感情エンジンなし |
| --- | --- | --- |
| 和解の台本の叱責中（ターン6〜10）の平均 | −0.14 | −0.45 |
| 和解の台本の謝罪後（ターン12〜20）の変動幅 | 0.23 | 0.45 |
| 称賛から立腹へ向かう台本の発覚後（ターン12〜20）の変動幅 | 0.60 | 0.47 |

和解の台本の変動幅は前章と同じく感情エンジンありのほうが小さくなりました。一方で称賛から立腹へ向かう台本では逆でした。叱責中の平均は前章とは逆に感情エンジンありのほうが下がっていません。覚醒が低い消沈の状態が穏やかな言葉として出た可能性はありますが、この検証だけでは判断できません。モデル同士の比較は第8章で行います。

### 性格による違い

性格によって状態の変化の幅と応答への反映のされ方が変わりました。

天邪鬼の状態は両方の台本で変化の幅が小さく、valenceの3回の平均の最大値は+0.53でした。申告が小さめになる傾向は前章と同じです。応答については先ほどのとおり、天邪鬼では状態と応答の感情スコアが連動しませんでした。

### 検証の限界

限界は前章と同じです。加えて感情エンジンなしの構成も今回取り直したため、その数値は前章の感情エンジンなしの数値とは一致しません。この差は、同じ条件でも結果がこの程度変わるというばらつきの目安になります。

## まとめ：次元パラメーター型で得たものと足りないもの <!-- 未レビュー -->

円環モデルの利点は外部状態が小さいことです。2つの数値と更新時刻だけで、状態は出来事に応じて変化し謝罪をきっかけに転換しました。感情の名前に縛られないので、前章では記録する場所がなかった懐かしさのような感情も、静かで少し快い位置として表せます。

足りない点は2つあります。1つは対極の感情の両立を区別できないことで、懐かしさに含まれる甘さと苦さの同居も表せません。もう1つは感情が生じた理由が記録されないことです。覚醒が高く不快な位置にあっても、侵害への怒りなのか脅威への恐れなのかは2つの数値からは分かりません。

次章では感情が生じた理由を外部状態に記録する評価導出型を扱います。
