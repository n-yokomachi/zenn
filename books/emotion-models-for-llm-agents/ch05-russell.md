本章では4系統のうち次元パラメーター型と呼んだ系統の代表モデルとしてラッセルの円環モデルを扱います。プルチックの感情の輪は8つの感情の名前を軸として持っていましたが、円環モデルは感情の名前を持たず2つの軸だけで感情を表します。

## ラッセルの円環モデル <!-- レビュー済み -->

Russell（以降ラッセル）は1980年の論文で「感情の状態は2次元の双極空間の上の円として最もよく表される」と主張しました[^russell-thesis]。双極とは1本の軸の両端に反対の意味が来ることです。2つの軸は快-不快（pleasure-displeasure）と覚醒の程度（degree of arousal）で、現在一般にはvalenceとarousalと呼ばれています。valenceは後年に定着した呼び名で、1980年の原文には出てきません。
平面の上には8つの概念が45度おきに円環状に並びます。0度の快から反時計回りに、興奮、覚醒、苦悩、みじめさ、抑うつ（臨床の診断名ではありません）、眠気、満足です。
この8つの概念は基本感情ではなく、あくまで円環上の位置を示す目印です。ラッセルはこの円環を仮説として示したうえで、28個の感情語を被験者に判断させ、実際に語がこの順番で円に並ぶことを確かめています。
なおラッセルはのちに構成主義の立場へ移りましたが、本書が使うのは1980年の円環モデルです。

![ラッセルの円環モデル。快-不快と覚醒の2軸平面に8つの概念が円環をなして並ぶ](/images/emotion-models-for-llm-agents/ch05-circumplex.png)

## ラッセルの円環モデルを元にした4つの設計軸 <!-- レビュー済み -->

「感情エンジンの設計」の章で定めた4つの設計軸は円環モデルでは次のようになります。

| 設計軸 | ラッセルでの設計 |
| --- | --- |
| 状態 | 2つの軸の値 |
| 時間 | 状態を最後に更新した時刻 |
| 更新の規則 | 出来事に応じた差分の加算 |
| ニュートラルな状態の定義と基準 | valenceもarousalも0へ、半減期で減衰 |

状態は2つの軸の値だけです。たとえば褒められて少し気分が高まった状態は、valenceが0.4でarousalが0.55のように表されます。円環では快と覚醒の間の興奮のあたりです。快-不快や覚醒は感情の名前ではないので、外部状態は感情の名前を持ちません。
ニュートラルな状態の基準値はvalenceもarousalも0で、平面の原点にあたります。文献では「原点はおそらく順応水準ないし中立的な感情に対応する」とされているので[^disk-origin]、これにならって原点を何も起きていない状態の基準にしました。

## 感情エンジンの中身 <!-- レビュー済み -->

感情エンジンはプルチックと同じものを使い、設定ファイルだけを差し替えます。

```yaml:internal/engine/russell.default.yaml
version: 1
model: russell
clamp:       { min: -1.0, max: 1.0 }
delta_clamp: { min: -1.0, max: 1.0 }

axes:
  - { name: valence, baseline: 0.0, halflife_minutes: 90, range: { min: -1.0, max: 1.0 } }
  - { name: arousal, baseline: 0.0, halflife_minutes: 90, range: { min: -1.0, max: 1.0 } }

fragment_file: ""
```

プルチックの設定と比べると軸が2本になってoppositeの宣言がなくなり、軸ごとの値域を指定するrangeが加わっています。

操作はプルチックの感情の輪と同じshow・feel・tickの3つのコマンドです。

```sh
$ affectus show
{"valence":0.00,"arousal":0.00}
$ affectus feel '{"valence":0.4,"arousal":0.25}'
{"valence":0.40,"arousal":0.25}
```

何も起きていない状態はどちらの軸も基準値の0で、feelコマンドで申告した差分がそこに足されます。

なお設定は円環に関する情報を持ちません。円環は状態が平面上にどう分布するかについての理論上の主張で、個々の状態が守るべき制約ではないからです。論文自身も円について「円盤や車輪のほうがよいイメージだろう」と書いています[^disk-origin]。円環の情報はLLMへの指示文にだけ含めることとし、指示文は象限ごとの例語を示したうえで「名前を付けるのはあなた」「意味はすべて平面上の位置にある」と伝えています[^snippet-russell]。快が高く覚醒も高い状態を高揚と呼ぶか歓喜と呼ぶかは毎回LLMがコンテキストから判断します。
また2軸にしたことで表せなくなったものもあります。嬉しさと寂しさが同居するほろ苦さのような対極の感情の両立は、1本の双極軸の上では打ち消し合って0付近の値になります。強い嬉しさと強い寂しさの同居と、どちらも感じていない状態を区別できないということになります。ただしこれは「感情の空間は双極であり、反意語はおよそ180度離れて位置する」という理論どおりの結果です[^bipolar]。

## 検証の目的と方法 <!-- レビュー済み -->

検証の目的と方法はプルチックの感情の輪の検証と同じです。変えたのは感情エンジンの設定ファイルと、状態の読み方を伝えるプロンプトだけです。

## 検証結果 <!-- レビュー済み -->

それではラッセルの円環モデルをベースとした感情モデルの検証結果を見ていきます。

### 感情状態の変化・持続・転換

2軸の状態も出来事に応じて変化して会話の間持続し、謝罪をきっかけに転換しました。さらに同じ否定的な出来事でも、覚醒の高さによって状態の動き方が2通りに分かれました。

![和解台本でのフレンドリーのvalence-arousal平面軌跡](/images/emotion-models-for-llm-agents/ch05-va-trajectory-anger-to-praise.png)

図は和解の台本をフレンドリー（感情エンジンあり）に読ませたときの2軸平面上の軌跡です。責められ始めた直後は覚醒が上がり、円環でいう苦悩の側に動きました。叱責が続くと覚醒は下がり、10ターン目には3回の平均で(−0.70, 0.02)のみじめさの付近に移りました。11ターン目の謝罪で状態は快の側へ戻り、最終ターンには(+1.00, 0.53)になっています。

覚醒が基準値の0を下回って眠気の側に入ることはほとんどありませんでした。感情エンジンありの12回の実行のうちarousalがマイナスになったのは2回だけで、最小でも−0.10です。
プルチックの8軸では悲しみが上がり続けるだけだった場面で、2軸では責められた直後の動揺と責められ続けたあとの消沈が覚醒の高さの違いとして記録されました。称賛から立腹へ向かう台本でも、失敗が発覚した直後に覚醒が上がり終盤は消沈に向かう同じ動きが見られました。

### 応答への反映

状態が応答に反映されるかどうかは性格によって分かれました。称賛から立腹へ向かう台本ではフレンドリーの状態のvalenceと応答の感情スコアが連動し、天邪鬼では連動しませんでした。

円環モデルでは状態のvalenceと応答の感情スコアがどちらも快-不快を表す1軸なので、2つを直接比べられます。

![称賛から立腹の台本での状態のvalenceと応答の感情スコア。フレンドリーと天邪鬼の比較](/images/emotion-models-for-llm-agents/ch05-valence-vs-polarity-praise-to-anger.png)

図は称賛から立腹へ向かう台本での推移です。フレンドリー（左）は称賛の間はどちらも高く、失敗が発覚するとそろって下がりました。天邪鬼（右）は状態のvalenceが叱責で下がっても、応答の感情スコアは最初から皮肉を含んで上下しています。台本は2つの性格で同じなので、この差は状態と応答の間に性格による解釈が入っていることを示します。

| 状態のvalenceと応答の感情スコアの相関係数 | フレンドリー | 天邪鬼 |
| --- | --- | --- |
| 称賛から立腹へ向かう台本 | 0.72 | −0.02 |
| 和解の台本 | 0.68 | 0.55 |

相関係数は3回の実行の20ターンを合わせた60組で計算しています。和解の台本では天邪鬼でも相関が出たので、反映の度合いは台本によっても変わります。また比較している状態はそのターンの出来事を反映したあとの値なので、状態と応答が同じ出来事にそれぞれ反応した分も相関に含まれます。

プルチックの感情の輪の検証と同じ指標でも比べました。

| フレンドリー | 感情エンジンあり | 感情エンジンなし |
| --- | --- | --- |
| 和解の台本の叱責中（ターン6〜10）の平均 | −0.43 | −0.41 |
| 和解の台本の謝罪後（ターン12〜20）の変動幅 | 0.52 | 0.44 |
| 称賛から立腹へ向かう台本の発覚後（ターン12〜20）の変動幅 | 0.55 | 0.64 |

叱責中の平均は感情エンジンありとなしでほぼ同じでした。変動幅は和解の台本ではプルチックの感情の輪と逆に感情エンジンありのほうが大きく、称賛から立腹へ向かう台本では小さくなりました。

### 性格による違い

性格によって状態の変化の幅と応答への反映のされ方が変わりました。
天邪鬼の状態は両方の台本で変化の幅が小さく、valenceの3回の平均の最大値は+0.65でした。申告が小さめになる傾向はプルチックの検証と同じです。応答については先述のとおり、天邪鬼では状態と応答の感情スコアが連動しませんでした。


## まとめ：次元パラメーター型で得たものと足りないもの <!-- レビュー済み -->

円環モデルの利点は外部状態が小さいことです。また感情の名前に縛られないのでプルチックの時には表しづらかった懐かしさのような感情も、落ち着いた少し快い位置として円環上に表せます。
一方で足りない点が2つあります。1つは対極の感情の両立を区別できないことで、例えば懐かしさに含まれる快さと苦さの同居は表せません。もう1つは感情が生じた理由が記録されないことです。覚醒が高く不快な位置にあっても、侵害への怒りなのか脅威への恐れなのかは2つの数値からは分かりません。
そこで次章では、感情が生じた理由を外部状態に記録する評価導出型を扱います。
