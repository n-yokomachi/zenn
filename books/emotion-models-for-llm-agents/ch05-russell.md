前章の終わりに、名前を最初から外部状態に置かない、という方向を示しました。この章はその方向を実際に進みます。扱うのは、第2章で次元パラメーター型と呼んだ系統の代表、ラッセルの円環モデルです。理論の中身、外部状態への落とし込み、実装、実測という進み方は前章と同じで、実装も同じaffectusを使います。ただし外部状態は、8つの軸から2つの軸になります。この縮小で捨てたのは、名前だけではありませんでした。

## 円環モデル

Russell（以降ラッセル）が1980年の論文で立てた主張は、一文に凝縮されています。感情の状態は、2次元の双極空間の上の円として最もよく表される、というものです[^russell-thesis]。双極とは、1本の軸の両端に反対の意味が来ることです。前章の対極、つまり別々の2つの軸を宣言で対にする形とは別物で、この違いはのちほど実装の形に直結します。

2つの軸の中身は、快-不快（pleasure-displeasure）と覚醒の程度（degree of arousal）です。第3章で触れたとおり、この2軸は今日valenceとarousalという呼び名で通っていますが、valenceは後年に定着した呼称で、1980年の原文には登場しません。

その平面の上に、8つの概念が45度おきの円環をなして並びます。0度の快から反時計回りに、興奮、覚醒、苦悩、みじめさ、抑うつ（気分が沈んだ状態のことで、臨床の診断名ではありません）、眠気、そして315度の満足です。

![ラッセルの円環モデル。快-不快と覚醒の2軸平面に8つの概念が円環をなして並ぶ](/images/emotion-models-for-llm-agents/ch05-circumplex.png)

この8つは、基本感情のリストではありません。プルチックの8つが理論の定める特権的なカテゴリーだったのに対して、ラッセルの8つは円環上の方位を示す目印です。研究で実際に配置されたのは28の感情語で、8つの概念の間にも語は連続的に並びます。8つという数が一致することに、理論上の意味はありません。

図の読み方を3つ補っておきます。まず、この45度おきという角度は要旨に書かれた円順序で、本書の図もそれに従った等間隔で描いています。原図の点の位置は、類似性データから求めた統計的な配置です。次に、横軸の左端にあるみじめさが、軸の名前としての不快に相当します。論文も、要旨ではこの位置を不快（displeasure）と書き、本文の図ではみじめさ（misery）と書いています。315度の満足も同様に、要旨ではリラックス（relaxation）です。語彙の揺れは前章で見たプルチックと同型で、本書の図は本文の図のラベルに従います。最後に、0度の快と90度の覚醒は、円環上の概念であると同時に軸の端でもあります。同じ語が二役を務めていることは、原図のままです。

この円環は、並べてみたら丸く見えた、という種類の主張ではありません。ラッセルは28語の配置を、3つの独立な手法で求めています。円環上の位置を直接推定させるスケーリング、語どうしの類似性から配置を導く多次元尺度構成法、そして快-不快と覚醒のそれぞれについての一次元の評定です。3つの解はほぼ一致しました（解の一致度で0.94から0.95です）。これとは別に、343名の自己報告の主成分分析でも2次元の構造が確認されています。手法の数理には入りませんが、円環が複数の測り方で再現された配置だという点だけ押さえれば、この章には十分です。

ラッセル自身がのちに構成主義へ立場を移したことは第2章で述べました。本書が実装に使うのは、その移動の起点にあたる1980年の円環モデルです。

## 4つの問いへの、ラッセルの答え

第3章の4つの問いに、このモデルで答え直します。

| 第3章の問い | ラッセルでの答え |
|---|---|
| 状態そのもの | 2つの軸の値 |
| 時間 | 状態を最後に更新した時刻 |
| 更新の規則 | 出来事に応じた差分の加算 |
| 基準と戻り方 | valenceは0へ、arousalは0.3へ、半減期で減衰 |

時間と更新の規則は、前章と同じ答えです。違いは1行目と4行目にあります。

状態そのものは、2つの軸の値だけになります。valenceが0.4でarousalが0.55、という形です。ここで、前章から消えたものがあります。8軸の外部状態は、軸の名前そのものが感情の名前でした。喜びの軸に量が立てば、そこに喜びの名前が付いていました。2軸の名前は、快-不快と覚醒です。これは感情の名前ですらありません。第3章の整理で、次元パラメーター型は感情の名前を外部状態のどこにも置かない型でした。その言葉どおり、名前が外部状態から消えています。量と関係の宣言で書かれていた外部状態が、2つの値だけになりました。

基準と戻り方には、前章になかった要素が入ります。基準が非ゼロです。valenceの基準は0ですが、arousalの基準は0.3で、何も起きていない落ち着いた状態に、静かな覚醒が残ります。落ち着きは無感情ではない、という判断を外部状態が形にしています。

ただし、この0.3という数字の出どころは正確に書いておきます。理論の側にあるのは、平面の原点はおそらく中立の感じに対応するだろう、という一文の示唆までです[^disk-origin]。覚醒の軸を0から1に取るなら、その中立は中点に相当します。安静を中点よりやや低い0.3に置いたのは、実装側の設計判断です。前章で引いた線、理論が決めているのは1つ目の中身だけ、はこのモデルでも成立します。理論は軸の数と意味を決め、基準値の数字は決めていません。

## 同じエンジン、違う設定

affectusのラッセル実装に、新しいエンジンはありません。プルチックを動かしたのと同じエンジンが、設定ファイルの差し替えでこのモデルを動かします。設定の全文です。

```yaml:internal/engine/russell.default.yaml
version: 1
model: russell
clamp:       { min: -1.0, max: 1.0 }
delta_clamp: { min: -1.0, max: 1.0 }

axes:
  - { name: valence, baseline: 0.0, halflife_minutes: 90, range: { min: -1.0, max: 1.0 } }
  - { name: arousal, baseline: 0.3, halflife_minutes: 90, range: { min:  0.0, max: 1.0 } }

fragment_file: ""
```

前章の設定と見比べると、軸が2本になり、oppositeの宣言が消え、rangeという軸ごとの指定が増えています。後の2つを順に見ます。

対極の宣言がないのは、書けないからではなく、書く必要がないからです。快と不快は、2つの軸ではなく1本の軸のプラス側とマイナス側です。前章がoppositeの宣言で表した対極の関係は、ここでは軸の形そのものに畳み込まれています。冒頭で双極と対極を区別したのは、この違いのためです。

rangeは軸ごとの値域で、valenceは−1から+1、arousalは0から1です。この非対称は、理論と実装の合作です。快-不快が両極を持つことは、理論の主張をそのまま写しています。一方、円環の縦軸は覚醒と眠気を上下の対極に置いていました。その軸を量として持ち直し、眠気の側を覚醒0と読み替えたのは実装側の設計です。眠気を、覚醒と対をなすもう1つの量としてではなく、覚醒が乏しい状態として読む、という判断です。範囲の外に出た値は端で切り詰められ、arousalは負になりません。なお、この軸ごとの値域は、非対称な値域を持つこのモデルを載せるためにエンジンへ加わった機構です。エンジンが両モデルを設定だけで動かせる状態は、最初からあったのではなく、こうして広げられてきたものです。

操作は前章と同じshow・feel・tickの3つで、エージェントへの組み込みも前章の2つのループのままです。変わったのは出力の形だけです。

```sh
$ affectus show
{"valence":0.00,"arousal":0.30}
$ affectus feel '{"valence":0.4,"arousal":0.25}'
{"valence":0.40,"arousal":0.55}
```

最初のshowに注目してください。まだ何も起きていない初期状態で、arousalが0.30を返しています。前節の、落ち着きは無感情ではないという答えが、コマンドの出力にそのまま現れています。続くfeelの出力も、arousalの0.55は差分0.25が基準値0.30に足された結果です。

## 円環は外部状態に書かれない

ここまでを前章と見比べると、理論のどこまでが外部状態に写るか、という線の引き方が1つ精密になります。軸そのものの形、つまり極性や値域には、理論とその読み替えが写っていました。では、理論の名前になっている円環そのものは、どこに写ったのでしょうか。

プルチックは、輪という関係構造を設定に書き込んでいました。対極はoppositeの宣言が、隣接は軸の並び順が担っていました。ラッセルの設定を見返すと、どちらもありません。2本の軸があるだけで、円環はどこにも書かれていません。

これは手抜きではありません。円環は、感情の状態が空間の中でどう分布するかについての理論の主張であって、個々の状態が従うべき制約ではないからです。実装も、状態を円周へ射影したり、中心からの距離に制約を掛けたりはしていません。論文自身に、円という図形よりも円盤や車輪のほうがよい比喩だという一節があります[^disk-origin]。中程度の強度の状態は空間の中心寄りに落ちる、という説明です。円環は外周の絵ではなく、平面全体に状態が分布するときの構造です。だから、中心付近にある、どっちつかずの弱い状態も、平面上の点として外周の強い状態と等しく持てます。

では、円環はどこへ行ったのか。前章では、演算に入れなかった対極の関係が、宣言と読解の材料として生き残りました。ラッセルでは、宣言すら残りません。円環が生き残る唯一の場所は、LLMに渡す読み方の指示です。affectusのプロンプトの雛形（examples/system-prompt-snippet-russell.md）は、2つの軸は組み合わさって状態の円環をなすと伝えたうえで、象限ごとの例語を添えます。高い快と高い覚醒ならexcitedやelatedのあたり、という形です。ただし、どの例語も名前を確定しません。雛形の指示は明快です。「名前を付けるのはあなた」。そして「意味は平面上の位置にだけ宿る」[^snippet-russell]。

第3章の整理を思い出すと、次元パラメーター型は、命名の仕事を丸ごとLLMに渡す、LLMに委ねる解釈の仕事がいちばん多い型でした。その言葉の実地がこれです。快で覚醒が高いという位置を高揚と呼ぶか歓喜と呼ぶかは、外部状態のどこにも書かれておらず、毎回、読み取る側が文脈の中で決めます。

代わりに失ったものもあります。両価です。前章では、嬉しさと寂しさが同居するほろ苦さのような両価的な状態は、対極の2軸が同時に立つという形で数値の上に現れる設計でした。valenceは1本の双極軸ですから、この同居は打ち消し合って0付近の値に潰れます。valenceの上では、強い嬉しさと強い寂しさの同居が、どちらもほとんど感じていない平静と見分けられません。覚醒の高さに痕跡が残るとしても、その値が両価の同居によるものなのか、ただ高ぶった中立なのかは、数値から復元できません。ほろ苦さの置き場が、今度は軸の形そのものによって消えました。これは実装の欠陥ではなく、理論に忠実な帰結です。感情の空間は双極であり、反意語はおよそ180度離れて落ちる、というのが原文の主張です[^bipolar]。両価を潰すことは、この理論を選ぶことの一部です。

対極まで行かない両立も、同じ運命をたどります。前章の実測では、相手への受容を保ったまま悲しむという両立が、別々の軸の上に見えていました。受容と悲しみは対極ではないので両価ではありませんが、2軸の外部状態では、この2つも別々の軸を持たず、1つの点に畳まれます。8軸で見えていた分化が、2軸では見えません。

そしてもう1つ。この外部状態は、なぜ快が下がったのかを覚えていません。この足りなさには、章の最後で戻ります。

## 実測、2軸は会話でどう動くか

実験の設計は前章と同一です。同じ2本の台本を、同じ2つの性格のエージェントに、affectusあり・なしの2構成で読ませ、反復は3回。モデルも呼び出し方も、応答を極性で判定する方法も前章のとおりです。変えたのは、affectusの設定ファイルと、状態の読み方を伝えるプロンプトの2つだけで、エンジンのコードは前章の実測と同一です。外部状態のモデルだけを差し替えた再実験になります。

まず状態の側です。次の図は、和解の台本、つまり理不尽に責められて11ターン目に謝罪される20ターンを、フレンドリー（affectusあり）が読んだときの、2軸平面上の軌跡です。

![和解台本でのフレンドリーのvalence-arousal平面軌跡](/images/emotion-models-for-llm-agents/ch05-va-trajectory-anger-to-praise.png)

前章で8本の折れ線だったものが、平面の上の1本の軌跡になります。責められ始めると、まず覚醒が上がります。valenceが沈んだまま覚醒が高い、円環でいえば苦悩のあたりです。ところが叱責が続くと、覚醒は下がり始めます。10ターン目には3回の平均で(−0.65, 0.15)、沈んだまま静かになった、抑うつのあたりの位置です。11ターン目の謝罪で軌跡は折り返し、快の側へ大きく戻って、最終ターンには(+1.00, 0.62)に着きます。valenceは3回とも上限の+1.0に達しました。快と興奮のあいだで会話が終わっています。

同じ負の出来事に、2つの経路があります。急に責められた直後は、覚醒が上がる動揺です。責められ続けた末は、覚醒が下がる消沈です。前章の8軸では悲しみの量が積み上がる一方だった場面で、2軸の平面は、同じつらさの中の質の違いを覚醒の高低として写しました。もう1本の、称賛から立腹へ向かう台本でも同じ型が見えます。11ターン目に失敗が発覚すると覚醒が先に跳ね上がり、快が落ちて苦悩のあたりを通り、叱責の続く終盤は消沈へ向かいます。

いま、苦悩のあたり、抑うつのあたり、と書きました。外部状態のどこにも書かれていない円環の語彙が、軌跡を読むときには自然に出てきます。円環は状態の制約としてではなく分布の読み方として働く、という前節の主張が、実測の平面の上でも同じ形で現れています。

天邪鬼の軌跡は、両台本とも振幅が小さいままでした（valenceの最大は+0.53です）。申告が控えめになる傾向は前章と同じで、性格が変わると状態の動き方が変わるという観察も、モデルを替えて再現されました。

次に応答の側です。このモデルでは、前章にはできなかった突き合わせが1つできます。状態のvalenceと、判定器の極性は、どちらも快-不快の1軸です。軸の意味が揃っているので、状態が応答の言葉に透けているなら、2つの系列は連動するはずです。次の図は、称賛から立腹の台本での、状態のvalenceと応答の極性です。

![称賛から立腹の台本での状態のvalenceと応答の極性。フレンドリーと天邪鬼の比較](/images/emotion-models-for-llm-agents/ch05-valence-vs-polarity-praise-to-anger.png)

フレンドリー（左）では、2本の線が連動します。称賛の間はどちらもおおむね高く、失敗の発覚を境にそろって沈みます。相関はr=0.66です。天邪鬼（右）では、状態のvalenceが褒められてゆるやかに上がり、叱責で沈んでいく一方、応答の極性は最初から皮肉の色で振れ続け、2本の線は連動しません。相関はほぼゼロです（r=−0.02）。この実験では、状態が言葉に透けるかどうかが、性格で分かれました。台本は2つの性格で同一ですから、台本が沈んだから状態も応答も沈んだだけ、という説明ではこの差は出ません。状態と応答の間に性格という解釈の層が挟まっていることの、応答の側からの証拠です。

この読みには限定を3つ付けます。相関は20ターンと3回の実行の全体で見た値で、ターン単位では振れます。図の左の終盤にも、状態が沈んだまま極性が跳ね上がるターンがあります。突き合わせている状態は、そのターンの出来事を織り込んだ、差分の適用後の値です。つまりこの相関には、状態と応答が同じ出来事にそれぞれ反応した分も含まれます。そして、もう1本の和解の台本では、天邪鬼にもr=0.41の相関が出ました。透け方は性格だけでなく、台本にも依存します。

前章の観察と比べられる数値も2つ確認しました。和解の台本の転換後のターンごとの振れ幅は、ありのほうが小さく（フレンドリーで0.23対0.45です）、前章と同じ向きの差が、モデルを替えて再現されました。もう1本の、称賛から立腹の台本では、この差の向きは逆で、ありのほうが大きく振れました。振れ幅の差し引きも台本に依存します。一方で、叱責フェーズ後半（ターン6〜10）の極性の平均は、ありが−0.14、なしが−0.45で、前章とは逆に、ありのほうが沈みませんでした。低覚醒の消沈の状態が、静かで角の立たない言葉に出た可能性はありますが、この実験だけでは決められません。外部状態の中身が違えば言葉への出方も違う、という観察にとどめます。モデルどうしを数値で並べる比較は、終章に譲ります。

留保は前章と同じです。反復は3回で、統計的な検定はしていません。affectusなしの構成も前章と同じ条件のまま今回取り直しており、その数値は前章のなしの数値とは一致しません。同じ条件でもこの程度は動く、というばらつきの目安でもあります。台本は2本、判定器は極性1軸で、温度は制御できません。ここから言えるのは、この台本ではこう見えた、までです。

## 次元パラメーター型で得たもの、足りないもの

得たものの1つ目は、外部状態の小ささです。2つの数値と更新時刻。それだけで、状態は立ち上がり、会話のあいだ持続し、謝罪という出来事で転換しました。管理する対象としては、これ以上ないほど身軽です。

2つ目は、名前の自由です。名前が固定されていないので、前章で置き場のなかった懐かしさのような色合いも、平面の上のこのあたり、静かで少し快い位置、としては持てます。ただし、持てるのはその穏やかな側面までです。懐かしさの核心にある甘さと苦さの同居、つまり両価の部分は、双極軸の上では潰れます。軸にない気分の置き場という前章からの問題への答えは、半分だけです。

足りないものは、より根本的なところにあります。この外部状態は、出来事を覚えていません。同じ高覚醒で不快のあたりにいても、それが侵害への怒りなのか、脅威への恐れなのかの区別は、2つの数値のどこにもありません。名前の区別だけなら、前章の8軸に戻れば付きます。しかし、なぜその位置に来たのかは、8軸も覚えていません。何があってこの位置に来たのか。それを知っているのは会話ログだけで、外部状態は答えられません。

なら、そのなぜを外部状態の側に置く、という方向がありえます。感情を、出来事の評価から導く設計。それが次章で扱う評価導出型です。

[^disk-origin]: 原文"although a disk or a wheel would be a better image, since affective states of moderate intensity would fall toward the middle of the space, with the origin presumably corresponding to adaptation level or a neutral feeling"（p. 1170）。原文の言い方では、原点は順応水準（adaptation level）ないし中立の感じに対応します。順応水準は、刺激に慣れたときに落ち着く基準の水準のことです。
[^snippet-russell]: 雛形の原文は"You name the feeling."と"the meaning lives entirely in the position on the plane."です。
[^bipolar]: 原文"Affective space is bipolar, with antonyms falling approximately 180° apart."（p. 1167）。
