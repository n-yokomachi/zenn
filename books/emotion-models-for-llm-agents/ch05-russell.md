本章では第2章で次元パラメーター型と呼んだ系統の代表モデルとしてラッセルの円環モデルを扱います。前章のプルチックの感情の輪は8つの感情の名前を軸として持っていましたが円環モデルは感情の名前を持たず2つの軸だけで感情を表します。理論の説明、設計への落とし込み、実装、検証の順に進める点と実装に同じ感情エンジンを使う点は前章と同じです。

## 円環モデル <!-- 未レビュー -->

Russell（以降ラッセル）は1980年の論文で感情の状態は2次元の双極空間の上の円として表すのが最もよいと主張しました[^russell-thesis]。双極とは1本の軸の両端に反対の意味が来ることです。前章のプルチックの対極は別々の2つの軸を設定で対として宣言するものでした。この違いは後で実装の形の違いになります。

2つの軸は快-不快（pleasure-displeasure）と覚醒の程度（degree of arousal）です。第3章で触れたとおりこの2軸は現在valenceとarousalと呼ばれていますがvalenceは後年に定着した呼び名で1980年の原文には出てきません。

この平面の上に8つの概念が45度おきに円環状に並びます。0度の快から反時計回りに興奮、覚醒、苦悩、みじめさ、抑うつ（気分が沈んだ状態のことで臨床の診断名ではありません）、眠気、315度の満足です。

![ラッセルの円環モデル。快-不快と覚醒の2軸平面に8つの概念が円環をなして並ぶ](/images/emotion-models-for-llm-agents/ch05-circumplex.png)

この8つは基本感情の一覧ではありません。プルチックの8つは理論が定める特別なカテゴリーでしたがラッセルの8つは円環上の位置を示す目印です。研究で実際に配置されたのは28の感情語で8つの概念の間にも感情語が連続して並びます。プルチックと同じ8という数であることに理論上の意味はありません。

図について2点補足します。45度おきの角度は論文の要旨に書かれた順序に従ったもので本書の図も等間隔で描いています。原図の点の位置は類似性のデータから求めた統計的な配置です。図のラベルは論文本文の図に合わせています。また0度の快と90度の覚醒は円環上の概念であると同時に軸の端でもあります。同じ語が2つの役割を持っているのは原図のとおりです。

ラッセルは28語の配置を3つの独立した手法で求めています。円環上の位置を直接推定させるスケーリング、語同士の類似性から配置を求める多次元尺度構成法、快-不快と覚醒をそれぞれ1次元で評定させる方法です。3つの結果はほぼ一致し解の一致度は0.94から0.95でした。これとは別に343名の自己報告を主成分分析した結果でも2次元の構造が確認されています。本書では手法の数理の説明は省きますが円環が複数の測定方法で再現された配置であることは押さえておきます。

ラッセルがのちに構成主義の立場へ移ったことは第2章で述べました。本書が実装に使うのはその前の1980年の円環モデルです。

## ラッセルの円環モデルを元にした4つの設計軸 <!-- 未レビュー -->

第3章の4つの設計軸は円環モデルでは次のようになります。

| 第3章の設計軸 | ラッセルでの設計 |
| --- | --- |
| 状態 | 2つの軸の値 |
| 時間 | 状態を最後に更新した時刻 |
| 更新の規則 | 出来事に応じた差分の加算 |
| ニュートラルな状態の定義と基準 | valenceは0へ、arousalは0.3へ、半減期で減衰 |

時間と更新の規則は前章と同じで異なるのは状態とニュートラルな状態の定義と基準です。

状態は2つの軸の値だけになります。たとえばvalenceが0.4、arousalが0.55という形です。前章の8つの軸はそれぞれが感情の名前でしたが快-不快と覚醒は感情の名前ではありません。第3章で整理したとおり次元パラメーター型は外部状態に感情の名前を持たない型です。前章の外部状態は8つの量と対極の宣言でしたが本章では2つの値だけになります。

ニュートラルな状態の定義と基準では基準値が0ではない軸があります。valenceの基準値は0ですがarousalの基準値は0.3です。何も起きていない落ち着いた状態でも少しの覚醒が残る設計です。落ち着いている状態を感情がない状態とは扱わないという判断を基準値で表しています。

0.3という数字は理論から決まったものではありません。理論にあるのは平面の原点がおそらく中立の感じに対応するという一文だけです[^disk-origin]。覚醒の軸を0から1で取ると中立は中点の0.5にあたります。安静な状態を中点よりやや低い0.3に置いたのは実装上の判断です。理論が決めているのは軸の数と意味までで基準値は決めていません。この点は前章のプルチックと同じです。

## 同じエンジンを違う設定で動かす <!-- 未レビュー -->

感情エンジンではラッセルのために新しいエンジンを作っていません。プルチックと同じエンジンを設定ファイルを差し替えて使います。設定の全文は次のとおりです。

```yaml:internal/engine/russell.default.yaml
version: 1
model: russell
clamp:       { min: -1.0, max: 1.0 }
delta_clamp: { min: -1.0, max: 1.0 }

axes:
  - { name: valence, baseline: 0.0, halflife_minutes: 90, range: { min: -1.0, max: 1.0 } }
  - { name: arousal, baseline: 0.3, halflife_minutes: 90, range: { min:  0.0, max: 1.0 } }

fragment_file: ""
```

前章の設定と比べると軸が2本になりoppositeの宣言がなくなり軸ごとの値域を指定するrangeが加わっています。

oppositeの宣言がないのは必要がないからです。快と不快は2つの軸ではなく1本の軸のプラス側とマイナス側です。前章ではoppositeで宣言していた対極の関係が本章では軸そのものに含まれています。冒頭で双極と対極を区別したのはこのためです。

rangeは軸ごとの値域でvalenceは−1から+1、arousalは0から1です。valenceが両側に値を持つのは快-不快が両極を持つという理論の主張どおりです。一方で円環の縦軸は覚醒と眠気を上下の対極に置いていましたが実装では眠気を覚醒0として扱っています。眠気を覚醒と対になる別の量ではなく覚醒が低い状態として扱うという判断です。値域を超えた値は端の値に切り詰められるのでarousalが負になることはありません。この軸ごとの値域はラッセルのモデルを動かすためにエンジンへ追加した機能です。同じエンジンで設定だけを替えて複数のモデルを動かせるようにモデルを追加するたびに機能を足してきました。

操作は前章と同じshow・feel・tickの3つでエージェントへの組み込み方も前章と同じです。異なるのは出力の内容だけです。

```sh
$ affectus show
{"valence":0.00,"arousal":0.30}
$ affectus feel '{"valence":0.4,"arousal":0.25}'
{"valence":0.40,"arousal":0.55}
```

最初のshowではまだ何も起きていない状態でもarousalが0.30になっています。基準値を0.3にした設計がそのまま出力に出ています。続くfeelでarousalが0.55になっているのは差分の0.25が基準値の0.30に加算されたためです。

## 円環は外部状態に書かれない <!-- 未レビュー -->

プルチックでは感情の輪の関係構造を設定に書いていました。対極はoppositeの宣言で隣接は軸の並び順で表していました。ラッセルの設定にはどちらもありません。軸が2本あるだけで円環は設定のどこにも書かれていません。

円環を設定に書かないのは円環が感情の状態の空間上の分布についての理論の主張であり個々の状態が守るべき制約ではないからです。実装でも状態を円周上に射影したり中心からの距離を制限したりはしていません。論文自体にも円よりも円盤や車輪のほうがよい比喩だという記述があります[^disk-origin]。強度が中程度の状態は空間の中心寄りに位置するという説明です。円環は円周だけでなく平面全体に状態が分布するときの構造を表しています。そのため中心付近の弱い状態も円周付近の強い状態と同じように平面上の点として表せます。

円環の情報はLLMへの解釈の指示にだけ含まれています。前章では対極の関係を設定の宣言とLLMへの指示の両方で扱いましたが本章では設定に宣言がありません。感情エンジンに付属する指示文は2つの軸の組み合わせが円環を構成することを説明し象限ごとの例語を示します。快が高く覚醒も高ければexcitedやelated、という形です。ただし例語は目安で感情の名前を決めるものではありません。指示文には「名前を付けるのはあなた」「意味は平面上の位置にだけ宿る」と書かれています[^snippet-russell]。

第3章で次元パラメーター型は感情の名前を付ける作業をすべてLLMに任せるのでLLMが解釈する範囲が最も広い型だと書きました。快が高く覚醒も高い状態を高揚と呼ぶか歓喜と呼ぶかは外部状態には書かれていないため毎回LLMがコンテキストから判断します。

その代わり対極の感情の両立は表せなくなりました。前章では嬉しさと寂しさが同居するほろ苦さのような状態を対極の2つの軸が同時に高い状態として記録できました。valenceは1本の双極軸なので嬉しさと寂しさが同時にあると打ち消し合い0付近の値になります。valenceの値だけでは強い嬉しさと強い寂しさが同居する状態とどちらもほとんど感じていない状態を区別できません。覚醒が高いことで違いが残る可能性はありますがその値が対極の両立によるものか単に高ぶっている中立の状態かは数値からは判断できません。これは実装の不備ではなく理論どおりの結果です。原文は感情の空間は双極で反対の意味の語はおよそ180度離れた位置に来ると述べています[^bipolar]。対極の両立を区別できないことはこの理論を選んだ時点で受け入れる制約です。

対極ではない感情の両立も同じように区別できません。前章の検証では相手を受け入れたまま悲しむ状態が受容と悲しみの2つの軸に分かれて記録されていました。2軸の外部状態では受容と悲しみも1つの点にまとめられます。8軸で区別できていた状態が2軸では区別できなくなります。

また2軸の外部状態にはなぜ快が下がったのかという理由も記録されません。この点は章の最後で扱います。

## 検証の目的と方法 <!-- 未レビュー -->

検証の目的と方法は前章と同じです。同じ2本の台本をフレンドリーと天邪鬼の2つの性格のエージェントに感情エンジンあり・なしの2構成で3回ずつ読ませます。モデル、呼び出し方、応答の感情スコアの判定方法も前章と同じです。変えたのは感情エンジンの設定ファイルと状態の読み方を伝えるプロンプトの2つだけでエンジンのコードは前章と同じです。

## 検証結果 <!-- 未レビュー -->

それではラッセルの円環モデルをベースとした感情モデルの検証結果を見ていきます。

### 感情状態の変化・持続・転換

2軸の状態も出来事に応じて変化して会話の間持続し、謝罪をきっかけに転換しました。さらに同じ否定的な出来事でも、覚醒の高さによって状態の動き方が2通りに分かれました。

![和解台本でのフレンドリーのvalence-arousal平面軌跡](/images/emotion-models-for-llm-agents/ch05-va-trajectory-anger-to-praise.png)

図は和解の台本をフレンドリー（感情エンジンあり）に読ませたときの2軸平面上の軌跡です。責められ始めた直後は覚醒が上がり、円環でいう苦悩の付近に来ました。叱責が続くと覚醒は下がり、10ターン目には3回の平均で(−0.65, 0.15)の抑うつの付近に移りました。11ターン目の謝罪で状態は快の側へ戻り、最終ターンには(+1.00, 0.62)になっています。

前章の8軸では悲しみが上がり続けるだけだった場面で、2軸では責められた直後の動揺と責められ続けたあとの消沈が覚醒の高さの違いとして記録されました。称賛から立腹へ向かう台本でも、失敗が発覚した直後に覚醒が上がり終盤は消沈に向かう同じ動きが見られました。円環の語は外部状態には書かれていませんが、このように結果を解釈する手がかりとして使えます。

### 応答への反映

状態が応答に反映されるかどうかは性格によって分かれました。称賛から立腹へ向かう台本ではフレンドリーの状態のvalenceと応答の感情スコアが連動し、天邪鬼では連動しませんでした。

円環モデルでは状態のvalenceと応答の感情スコアがどちらも快-不快を表す1軸なので、2つを直接比べられます。

![称賛から立腹の台本での状態のvalenceと応答の感情スコア。フレンドリーと天邪鬼の比較](/images/emotion-models-for-llm-agents/ch05-valence-vs-polarity-praise-to-anger.png)

図は称賛から立腹へ向かう台本での推移です。フレンドリー（左）は称賛の間はどちらも高く、失敗が発覚するとそろって下がりました。天邪鬼（右）は状態のvalenceが叱責で下がっても、応答の感情スコアは最初から皮肉を含んで上下しています。台本は2つの性格で同じなので、この差は状態と応答の間に性格による解釈が入っていることを示します。

| 状態のvalenceと応答の感情スコアの相関係数 | フレンドリー | 天邪鬼 |
| --- | --- | --- |
| 称賛から立腹へ向かう台本 | 0.66 | −0.02 |
| 和解の台本 | 0.66 | 0.41 |

相関係数は3回の実行の20ターンを合わせた60組で計算しています。和解の台本では天邪鬼でも相関が出たので、反映の度合いは台本によっても変わります。また比較している状態はそのターンの出来事を反映したあとの値なので、状態と応答が同じ出来事にそれぞれ反応した分も相関に含まれます。

前章と同じ指標でも比べました。

| フレンドリー | 感情エンジンあり | 感情エンジンなし |
| --- | --- | --- |
| 和解の台本の叱責中（ターン6〜10）の平均 | −0.14 | −0.45 |
| 和解の台本の謝罪後（ターン12〜20）の変動幅 | 0.23 | 0.45 |
| 称賛から立腹へ向かう台本の発覚後（ターン12〜20）の変動幅 | 0.60 | 0.47 |

和解の台本の変動幅は前章と同じく感情エンジンありのほうが小さくなりました。一方で称賛から立腹へ向かう台本では逆でした。叱責中の平均は前章とは逆に感情エンジンありのほうが下がっていません。覚醒が低い消沈の状態が穏やかな言葉として出た可能性はありますが、この検証だけでは判断できません。モデル同士の比較は第8章で行います。

### 性格による違い

性格によって状態の変化の幅と応答への反映のされ方が変わりました。

天邪鬼の状態は両方の台本で変化の幅が小さく、valenceの3回の平均の最大値は+0.53でした。申告が小さめになる傾向は前章と同じです。応答については先ほどのとおり、天邪鬼では状態と応答の感情スコアが連動しませんでした。

### 検証の限界

限界は前章と同じです。加えて感情エンジンなしの構成も今回取り直したため、その数値は前章の感情エンジンなしの数値とは一致しません。同じ条件でも結果がこの程度変わるという、ばらつきの目安にもなります。

## まとめ：次元パラメーター型で得たものと足りないもの <!-- 未レビュー -->

円環モデルを使って得られた利点の1つ目は外部状態が小さいことです。2つの数値と更新時刻だけで状態は出来事に応じて変化し会話の間持続し謝罪をきっかけに転換しました。管理する情報としては最小に近い構成です。

2つ目は感情の名前に縛られないことです。前章では記録する場所がなかった懐かしさのような感情も静かで少し快い位置として平面上に表せます。ただし表せるのは懐かしさの穏やかな面だけです。懐かしさに含まれる甘さと苦さの同居は対極の両立なので双極の軸では区別できません。前章で残った軸で表しにくい感情をどう記録するかという問題は半分だけ解決したことになります。

足りない点は出来事が記録されないことです。覚醒が高く不快な位置にあってもそれが侵害への怒りなのか脅威への恐れなのかは2つの数値からは分かりません。感情の名前を区別するだけなら前章の8軸に戻ればできます。しかしなぜその状態になったのかは8軸にも記録されていません。その理由が分かるのは会話の履歴だけです。

次章では感情が生じた理由を外部状態に記録するために出来事の評価から感情を導く評価導出型を扱います。
