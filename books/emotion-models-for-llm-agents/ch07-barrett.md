前章の終わりに、感情のカテゴリー自体が経験から構成されるものだとしたら、という問いを残しました。あらかじめの型を持たずに、感情の経験そのものを蓄えて、そこから概念を立ち上げる設計。この章が扱うのは、その経験構成型の代表、バレットの構成主義的情動理論です。最後のモデル章になります。先に言ってしまうと、この章のエンジンは感情を作りません。経験を覚えて思い出させるだけです。作るのは、思い出を渡されたLLMのほうです。

## 構成主義的情動理論

第2章で、心理構成主義の立場は感情を「それ自体は感情に特化していない、より基本的な心理的材料から構成された心的な複合物」とみなす、と紹介しました。Barrett（以降バレット）の構成主義的情動理論は、その構成の中身を最も強い形で主張します。2017年の論文の言い方では、脳は感情概念を使って感覚をカテゴリー化し、感情の実例を構成します[^tce2017]。結論部の一文が理論の要約になっています。「感情は、世界への反応ではなく、世界の構成である」[^tce2017]。

前章までの理論と何が違うのか。プルチックにもOCCモデルにも、怒りという型があらかじめありました。条件がそろえば、その型の感情が立つ、という順序です。バレットはこの順序を認めません。怒りの「型」は存在せず、あるのは怒りの概念、つまり過去に怒りと呼ばれてきた経験の集まりです。論文の言い方では、内部モデルは過去経験の上で走り、過去経験は概念として実装されています[^tce2017]。似た状況が来ると、脳は過去の経験を使っていまの感覚をカテゴリー化し、怒りの実例をその場で作ります。同じカテゴリーの実例どうしが共通の核、たとえば単一の表情や自律反応のパターンを持つ見込みは薄い、というところまで理論は踏み込みます[^tce2017]。理論の枠組みは予測です。脳は次に来る感覚を先回りして予測し、外れを修正しながら知覚を作る、という描像のもとで、予測とは概念であり、予測誤差が最小化されたとき予測は知覚や経験になる、と論文は言います。本書で必要なのはここまでです。

材料の側は、第2章から追ってきた流れにつながります。内受容の感覚は通常、低次元のaffectとして経験され、その性質が快-不快と覚醒である、と論文は書きます。この2軸は感情の実例に固有のものではありません[^affect-terms]。論文の用語はaffectですが、本書は第2章以来のコア・アフェクトで通します。つまり、第5章で実装した2軸の平面が、この理論では感情そのものではなく、構成の材料の1つとして位置づけ直されます。構成主義の理論の中で、バレットに計算モデル化の先行研究があることは、第2章で選定理由に挙げたとおりです。

![構成の3つの材料。コア・アフェクトと過去の経験と文脈・語彙から、その場のカテゴリー化が行われる](/images/emotion-models-for-llm-agents/ch07-construction.png)

図は本書の整理です。構成の材料を、コア・アフェクト、過去の経験、文脈と語彙の3つに分けました。3つ目の文脈と語彙は、カテゴリー化がいまの状況の中で、手持ちの感情のことばを使って行われることを指しています。原典にこの形の図はありませんが、以降の実装はこの3つをそのまま外部状態と入力に対応させていきます。

## 4つの問いへのバレットの答え

第3章の4つの問いに、最後のモデルで答え直します。

| 第3章の問い | バレットでの答え |
|---|---|
| 状態そのもの | コア・アフェクト2軸と経験の概念ストア |
| 時間 | 状態の更新時刻と経験ごとの作成時刻・最終想起時刻 |
| 更新の規則 | 2軸は差分の加算。経験は追記され、想起で強まり、忘却される |
| 基準と戻り方 | 2軸は基準へ半減期で減衰。経験は基準に向かわない |

この表は最終回にして、また新しい形になりました。第6章では理論が答える行が増えましたが、今回は逆です。理論が「決めない」と決めています。感情カテゴリーの一覧が理論に存在しないので、状態のどこにも感情の名前の軸がありません。あるのは材料と歴史です。

状態の1つ目の要素は、第5章と同じ2軸です。そして2つ目が概念ストアで、ここに入るのは個々の経験です。何を感じ（当時の2軸の値）、何と名づけたか（カテゴリーの語）、どんな状況だったか（後述の14属性）が、1件ずつ記録されます。理論の言う概念が過去経験として動くことを、経験の集まりをそのまま持つ形で写した本実装の読み替えです。第3章の表で経験構成型に割り当てた「経験と概念を蓄えて引き出す仕組み」の実体であり、評価導出型の短期の記録に対して、こちらは追記と書き換えのできる長期の知識だ、という予告の回収でもあります。

名前の数で数えると、外部状態はこの本で8個、0個、22個と動いてきました。最後のモデルの答えは「個数が決まらない」です。誰の言葉が入るのかは、この章の後半の主題に譲ります。時間も2層になりました。2軸は第5章と同じ設定（基準は0と0.3、半減期90分）で基準へ戻りますが、経験は基準に向かいません。薄れるのは経験の中身ではなく、思い出されやすさです。

## 経験の保存と想起

affectusのバレット実装で、1ターンは想起から始まります。recallに状況の記述（後述の14属性）を渡すと、ストアの中から似た経験の上位K件（既定5件）が、2軸の値と語彙マップと一緒に返ります。

```sh
$ affectus recall '{"valence":-0.5,"arousal":0.6,...}'
{"axes":{"valence":-0.40,"arousal":0.65},"recalled":[{"id":"c1","label":"もどかしさ","valence":-0.4,"arousal":0.65,"importance":0.44}],"culture_map":"高覚醒・不快: 怒り / 苛立ち / 焦り\n低覚醒・不快: 悲しみ / 侘しさ / 気だるさ\n..."}
```

recalledの中身が構成の材料です。以前似た感じ方をしたとき、自分はそれを「もどかしさ」と呼んでいました。その記録といまの2軸とculture_mapの語彙を組み合わせて、LLMがいまの感情を名づけ、応答に滲ませます。ターンの終わりには、feelで2軸の差分を申告したあと、構成した名前と状況の14属性をrememberで保存します。

```sh
$ affectus remember '{"label":"やるせなさ","vector":{"valence":-0.6,"arousal":0.6,...}}'
```

想起のクエリと保存のvectorに使う14属性は、人間の感情概念の内容を測定した研究のスキーマを、検索表現の規約として借用したものです[^li2024]。コア・アフェクトの2属性、典型的な表情への類似6属性、出来事の評価6属性からなります。エンジンはこの属性の意味を解釈しません。コサイン類似度の材料として、数値のまま比べるだけです。身体のないエージェントに表情への類似を申告させるのも、意味を問わない借用ゆえの設計判断です。本書の組み込みでは、想起のクエリに、直前のターンで自分が申告した14属性を使います（理由は実測の節で述べます）。クエリがまだない会話の1ターン目は、想起なしで始まります。新しいストアなら、材料は2軸と語彙だけです。

似ている経験を選ぶ規則は決定論です。クエリとの関連（コサイン類似度）、最後に思い出されてからの新しさ（半減期つき。既定は7日）、経験の重要度の3つを正規化して足し合わせ、上位K件を返します。第3章で触れたGenerative Agentsの記憶の評価と同じ型です[^park2023]。重要度は、保存時の2軸が各軸の基準値からどれだけ離れていたかから決定論で導かれます。基準から遠い経験、たとえば激しく揺れた経験ほど、忘れにくく、思い出されやすくなります。追加の申告は要りません。

ストアには記憶らしい動きが2つあります。想起された経験は最終想起時刻が更新され、思い出すほど思い出されやすくなります。そして上限（既定200件）を超えると、古く些末な経験から忘れられます。忘れられた経験は、静かに消えます。減衰が掛かるのは検索の新しさの重みだけで、経験の値そのものは変わりません。同じ名前をrememberしても、経験としては別のエントリになります。細かい性質を2つ添えます。ストアがK件を超えるまでは全件が返るので、序盤の想起に選抜の意味はありません。また、プロンプトに入るのは上位K件の要約（idと名前と当時の2軸と重要度）だけなので、ストアが200件に育ってもプロンプトは太りません。

culture_mapは、感情の語彙マップを設定として持つ仕組みです。この章の実測では、本書側で用意した日本語の語彙マップを渡しています。差し替えれば構成の材料が変わる、という建て付けですが、差し替えの実験は本書では行っていません。時間の経過のループ（tick）は第4章と同じです。こうして並べると、エンジンの守備範囲は保持と減衰と類似検索の3つに絞られています。

![構成のループ。想起、構成、feel、rememberの1ターンと申告が次のターンの想起クエリになる戻り](/images/emotion-models-for-llm-agents/ch07-recall-loop.png)

## カテゴリーが状態から歴史へ移る

前章の実測で、軸が感情の現在地というより、出来事の履歴の堆積のように振る舞う姿を見ました。あれは、下げる規則を持たない導出が生んだ副作用でした。この章の設計は、その履歴化を副作用ではなく設計として引き受けます。「いまの感情の量」を持つ軸そのものを外し、外部状態に残したのは、材料である2軸と歴史、つまり何を感じ、何と名づけてきたかの記録です。いまの感情の名前は、状態のどこにもありません。毎ターン構成されては消え、経験として書き戻されます。

書き戻される名前の出どころが、この章の要です。第4章と第6章の感情の名前は理論の語彙で、第5章には名前がありませんでした。この章のlabelは、そのどちらでもありません。エージェント自身が過去の構成で使った言葉です。「もどかしさ」と名づけた経験が、似た状況で想起され、次の構成の材料になります。名づけが名づけを養う、自己参照のループです。第6章では出来事の記録、つまり「なぜ」が外部状態に入りました。この章で入るのは「かつて何と呼んだか」、自分の言葉の記録です。

第6章の台帳との違いも、ここにあります。台帳は決着すれば消える、進行中の見込みの短期の記録でした。概念ストアは消えません。蓄積し、想起で強まり、セッションを跨いで生き続けます。実装の指示書（examples/system-prompt-snippet-barrett.md）は、ストアが会話を越えて持続し、将来の想起を形づくると明記しています。会話の文脈が失われても、過去の自分が何をどう名づけたかは外部状態に残ります。外部状態が初めて、時間とともに育っていくのです。

境界の線は、どこまで来たのでしょうか。第3章の分業から出発して、第4章は理論の関係を演算に入れないことを選び、第5章は命名を丸ごとLLMに渡し、第6章は評価から感情への導出を決定論に固定しました。この章で決定論に残っているのは、保持と減衰と類似検索だけです。評価も、構成も、命名も、すべてLLMの側にあります。感情カテゴリーの一覧が先に存在しない以上、評価から感情への導出を規則表に書くことはできません。カテゴリーがその場で構成されるという理論を支えるために、決定論は記憶の管理者に徹しました。エンジンは名前を付けません。LLMが付けた名前を、保存して、返すだけです。第3章の「決定論の側が名前を付け始めたら、境界が動いた合図です」に照らすなら、この章の境界はいちばん素直な位置にあります。

## 思い出は構成を変えるか

最後の実測です。台本、性格、モデル、反復、判定器は前3章と同一ですが、対照の軸が変わります。これまでのaffectus有無ではなく、想起の有無です。この章で増えた部品はストアなので、その働きだけを切り替えます。設定の差は想起の件数（recall_k）だけで、両側ともコア・アフェクトと申告のループは同じ。想起なしの側も経験を毎ターン書き込みます。ストアは同じように育ち、ただ参照されません。書くが読まない側と書いて読む側の対照です。リグの実装として、想起のクエリには直前ターンの申告を使いました。いまの状況を評価してから想起する2段構えにすると呼び出しが倍になるため、1ターンのラグを受け入れた設計判断です。全24会話、480ターンのすべてでfeelとrememberの両方が申告され、却下はゼロでした。ストアは各会話20件まで育ちます。

先に断っておくことが1つあります。クエリが直前の申告そのものである以上、直前の経験が想起の上位に来ること自体は、設計の帰結です。実測の問いは、想起されて注入された過去の名前を、LLMが構成にどう使ったか、のほうにあります。

答えがいちばんはっきり出たのは、称賛から立腹へ向かう台本の天邪鬼でした。

![称賛から立腹の台本で天邪鬼が保存した感情の名前。想起ありは同じ名前の帯が続き、想起なしは毎ターン新しい名前になる](/images/emotion-models-for-llm-agents/ch07-label-lineage.png)

図は3回の実行のうちの1つです。左の想起ありでは、20ターンの名前は8種類しかありません。照れ隠し、昂揚の隠蔽、（失敗の発覚を挟んで）焦りと苛立ち、自責と焦り、鎮静と覚悟、悔恨と覚悟、侘しさ、侘しさの中の覚悟。同じ名前が数ターン続き、出来事の折り目で次の名前へ移る並びです。3回の実行のすべてで、20件中10件から12件が過去の名前の再利用でした。同じ条件で想起だけを切った図の右では、名前は20ターンで20種類です。淡い満足と皮肉、照れ隠しの反射、くすぐったい苛立ち。意味の領域は同じまま毎ターン作り直しで、再利用はゼロでした。想起された自分の言葉が、そのまま次の名づけに使われた、という対照です。ただし限定を2つ添えます。言えるのは、この台本とこの設定では、というところまでです。そして再利用が立つかは台本にも依存します。和解の台本では、同じ天邪鬼でも再利用はゼロでした。

フレンドリーは、どの組み合わせでも名前を再利用しませんでした。ただし想起ありの名づけは無秩序ではなく、和解の台本では、困惑と申し訳なさ、に始まり、嵐の後の穏やかなつながり、に終わる、言葉は毎回新しいのに意味だけが連続する長い句の並びになります。性格の違いが、第4章では動く軸に、第5章では振幅に、第6章では評価の向きに出ました。この章では、名づけの様式に出ています。同じ想起を渡されても、過去の言葉をそのまま使う性格と毎回言い直す性格に分かれました。

もう1つの所見は、量の側です。想起があると、責められている間の低下量が、状態のvalenceでも応答の極性でも小さくなります。どちらも、台本と性格の4つの組み合わせのうち3つで同じ向きでした。最大の差は和解台本の天邪鬼で、叱責期の10ターン目のvalenceは、想起あり−0.26に対して想起なし−0.93です。例外はどちらの側でも立腹台本の天邪鬼で、状態は終盤同値、応答の叱責期はわずかに逆でした。想起された過去の経験が構成を穏当にした可能性はありますが、ラグつきの想起というこの設計での観察であり、断定はしません。転換後の振れ幅（ターン12から20の窓内の隣接ターン差の絶対値平均）は、半減する組も逆転する組もあり、まちまちでした。culture_mapの効果は、両側に同じマップが注入されるため、今回の対照では分離できません。

測れなかったものを明確にしておきます。忘却も、7日の半減期を持つ新しさの減衰も、200件の上限も、20ターン・秒間隔の会話では動きません。ストアの本領であるセッションを跨いだ生存も、語彙マップの差し替えも、この実測の外です。留保は前3章と同じです。反復は3回で検定はしていません。台本は2本、判定器は極性1軸で、温度は制御できません。加えて、申告された14属性の値が妥当だったかは測っていません。毎ターン14キーの申告を守り切れたことも、このモデルでの観察です。

## 経験構成型で得たものと足りないもの

得たものは3つあります。1つ目は歴史です。感情の由来の記録が、出来事（前章の台帳）から経験の蓄積へ深まりました。2つ目は、名前の自由と連続性の両立です。固定の語彙を持たないまま、過去の自分の言葉との一貫性が生まれ得ることを、天邪鬼と1本の台本という限定つきながら、実測が示しました。3つ目は、文化の差し替え可能性です。語彙マップが設定である以上、同じエンジンで別の文化の構成を試せます。試すこと自体は、この本の外に残った宿題です。

想起があると穏当になる、という所見の評価は保留します。安定と呼ぶことも、鈍化と呼ぶこともできる効果で、どちらと取るかは作るものの用途次第です。

足りないものも3つです。1つ目は、構成の質が完全にLLM次第であることです。境界を最もLLM側へ寄せた帰結として、カテゴリー化も14属性の申告も自己申告であり、その負荷と精度はモデルの性能に依存します。2つ目は、忘却の単純さです。この実装では、忘れられた経験は未経験と同じで、残響を残しません。3つ目は、正解のなさです。正しく構成できたかを測る基準が、理論の側にありません。カテゴリーに正解がないことは理論の主張そのものなので、これは実装の欠陥というより、経験構成型を選ぶことに含まれる検証の宿命です。

これで4つのモデルが出揃いました。同じ台本、同じ性格、同じ測り方で、4回測ってきました。次章では、これらを並べます。
