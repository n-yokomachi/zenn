本章では「感情モデルの整理」の章で経験構成型と呼んだ系統の代表モデルとして「バレットの構成主義的情動理論」を扱う。この理論では感情のカテゴリーは過去の経験から作られるとされる。本章の感情エンジンは感情の名前ごとの量を持たず、快-不快・覚醒の2軸の値と過去の経験を保存して返し、感情はLLMが過去の経験をもとにその場で作る。

## バレットの構成主義的情動理論 <!-- レビュー済み -->

Barrett（以降バレット）の構成主義的情動理論によると、脳は感情の概念を使って体の感覚をカテゴリー化しその場で感情を作るとされる[^tce2017]。論文の結論部には「感情は、世界への反応ではなく、世界の構成である」という一文がある[^tce2017]。この理論はここまでの3つの理論と前提が大きく違うので、実装に入る前に例を使って説明する。

### 感情の型を持たない理論

これまでに扱った理論には怒りのような感情の型が最初からあった。プルチックの感情の輪は8つの基本感情を定め、OCCモデルは評価の条件から導かれる22のタイプを定めていた。ラッセルの円環モデルも感情の名前こそ持たないが、円環上の8つの概念の並びは理論が示したものである。

バレットの理論には型がない。あるのは過去に怒りと呼んだ経験の集まりである怒りの概念だけである[^tce2017]。似た状況になると、脳は過去の経験を使って現在の感覚を怒りとしてカテゴリー化する。この見方では、怒りと呼ばれる経験に共通の形はない。声を荒らげる怒りもあれば黙り込む怒りもあり、心拍が上がる怒りもあれば顔から血の気が引く怒りもある。バレットは「1つの感情のカテゴリーのすべての実例が共通の核となる特徴を持つ見込みは薄い」とし、共通の核の例として1つの表情、自律神経の反応のパターン、ニューロンの組を挙げている[^tce2017]。つまり怒りという名前の下にある経験は、表情も体の反応も脳の働きも1つに決まらない。だからこの理論は怒りを型として定義せず、怒りと呼ばれた経験の集まりとして扱う。

型がない代わりに、この理論には感情を構成する材料がある。本書では材料をコア・アフェクト、過去の経験、コンテキストと語彙の3つに整理し、順に説明する。

### 材料1：コア・アフェクト

感情を作る材料の1つ目は、体の内部の感覚として経験される快-不快と覚醒である[^affect-terms]。
本書では「感情モデルの整理」の章と同じくコア・アフェクトと呼ぶ。ラッセルの円環モデルで実装した2軸の平面は、この理論では感情そのものではなく材料の1つである。たとえば心拍が上がり胸が締め付けられる感覚は、それだけでは不快で覚醒の高い状態であって、まだ恐れでも怒りでも焦りでもない。コア・アフェクトはどの感情にも先立つ材料で、それをどの感情として経験するかは次の2つの材料で決まる。

### 材料2：過去の経験

2つ目の材料は過去の経験である。理論では概念は過去の経験の集まりなので、過去に何を感じて何と名付けたかの蓄積がそのまま概念になる。
エージェントの例で考える。ユーザーに身に覚えのないことで責められ、不快で覚醒の高い状態を「もどかしさ」と名付けた経験があるとする。あとで似た状況になると、この経験が引き出され、今の感覚を「もどかしさ」としてカテゴリー化する材料になる。逆にそのような経験がなければ、同じコア・アフェクトでも別の名前が付く。概念が経験から作られるとは、このように名付けの材料が過去の経験から来るということである。

### 材料3：コンテキストと語彙

3つ目の材料は、現在のコンテキストと使える語彙である。同じコア・アフェクトでもコンテキストが違えば別の感情として構成される。心拍が上がる感覚は、大人数の前での発表の直前なら緊張として、誰かとの待ち望んだ再会の直前なら高揚として経験される。
語彙は構成に使える名前の候補を決める。「侘しさ」という言葉を知っていれば、不快で覚醒の低いある経験をその名前でラベル付けできる。知らなければ同じ経験は「悲しみ」や「気だるさ」など、別の言葉でラベル付けされる。

### 構成の流れ

3つの材料がそろうと、感情は次の流れで作られる。和解台本の9ターン目で、人間役が解約をほのめかす場面を例にする。

1. 責められている間の不快で覚醒の高いコア・アフェクトがある
2. 身に覚えのないことで責められた過去の経験が引き出される。そこには「もどかしさ」という名前が付いている
3. 今のコンテキストは、自分の落ち度ではない叱責のうえに解約の脅しが加わった場面である。使える語彙には、語彙マップが示す「怒り」「苛立ち」「焦り」と、LLM自身が知っている「やるせなさ」のような言葉がある
4. これらを合わせて、今の感覚を「やるせなさ」としてカテゴリー化する

感情とその名前は、このカテゴリー化の時点で決まる。カテゴリー化の前にあるのは不快で覚醒の高いコア・アフェクトだけで、「やるせなさ」という感情も名前もまだない。そして「やるせなさ」と名付けた経験は蓄積され、次に似た状況になったときの材料になる。

![構成の3つの材料。コア・アフェクトと過去の経験とコンテキスト・語彙から、その場のカテゴリー化が行われる](/images/emotion-models-for-llm-agents/ch07-construction.png)

実装ではこの3つの材料のうちコア・アフェクトと過去の経験を外部状態に持つ。コンテキストは会話から、語彙は感情エンジンが渡す語彙マップからLLMに与える。

## バレットの構成主義的情動理論を元にした4つの設計軸 <!-- レビュー済み -->

「感情エンジンの設計」の章で定めた4つの設計軸は構成主義的情動理論では次のようになる。

| 設計軸 | バレットでの設計 |
| --- | --- |
| 状態 | コア・アフェクト2軸と経験の概念ストア |
| 時間 | 状態の更新時刻と経験ごとの作成時刻・最終想起時刻 |
| 更新の規則 | 2軸は差分の加算。経験は追記され、想起で強まり、忘却される |
| ニュートラルな状態の定義と基準 | 2軸は基準値0へ半減期で減衰。経験は基準に向かわない |

この理論は感情のカテゴリーの一覧を定めていないので、状態には感情の名前の軸がない。状態はラッセルの円環モデルと同じ2軸と、個々の経験を記録する概念ストアである。概念ストアには、何を感じたか（当時の2軸の値）、何と名前を付けたか（感情を表す語）、どんな状況だったか（後述の14属性）を1件ずつ記録する。2軸はラッセルの円環モデルと同じく時間経過により基準値に戻るが経験の記録は特に基準点がないので変化しない。時間とともに下がるのは経験の思い出されやすさである。

## 感情エンジンの中身 <!-- 未レビュー -->

バレットの理論のために感情エンジンへ3つの機能を追加した。似た経験を想起するrecallコマンドと、今の経験を保存するrememberコマンド、そして経験を蓄える概念ストアである。

![構成のループ。想起、構成、feelコマンド、rememberコマンドの1ターンと、申告した14属性が次のターンの想起の検索条件になる戻り](/images/emotion-models-for-llm-agents/ch07-recall-loop.png)

1ターンは次の4つの手順で進む。

1. 想起: LLMがrecallコマンドで概念ストアから似た経験を引き出す
2. 構成: LLMが想起した経験と現在の2軸の値、語彙マップから今の経験に名前をつけて応答を作る
3. 2軸の更新: LLMがfeelコマンドで2軸の差分を申告する
4. 保存: LLMがrememberコマンドで今の経験を概念ストアに保存する。保存した内容が次のターンの想起の検索条件になる

感情エンジンが担当するのは概念ストアの検索と保存、2軸の保持と減衰である。評価と感情の構成、感情への名前付けはLLMが担当する。
以下、手順の順により詳細に説明しよう。

### 手順1：想起

LLMはターンの最初にrecallコマンドに14属性を渡す。14属性は経験を表す値で、中身は手順4で説明する。
感情エンジンは概念ストアから似た経験を最大5件返す。経験ごとに返るのはその経験に付けた名前とその経験に記録された2軸の値、そしてその経験の重要度である。下記の例では「もどかしさ」と名前を付けた以前の経験の例が返っている。

```sh
$ affectus recall '{"valence":-0.5,"arousal":0.6,...}'
{"axes":{"valence":-0.40,"arousal":0.65},"recalled":[{"id":"c1","label":"もどかしさ","valence":-0.4,"arousal":0.65,"importance":0.44}],"culture_map":"高覚醒・不快: 怒り / 苛立ち / 焦り\n低覚醒・不快: 悲しみ / 侘しさ / 気だるさ\n..."}
```

似た経験は、検索条件との関連度と最後に想起されてからの新しさ、そして重要度の3つの点数をもとに選ばれる。Generative Agentsの記憶の検索と同じ方式である[^park2023]。関連度は14属性のコサイン類似度である。新しさは最後に想起されてからの時間で半減期7日で下がり、想起されると元に戻る。重要度は保存したときの2軸が基準値から離れているほど高くなる。プロンプトに入るのは想起した経験だけなので、ストアが増えてもプロンプトは長くはならない。

### 手順2：構成

LLMは想起した経験の記録と現在の2軸の値、語彙マップを組み合わせて今の感情に名前をつけて応答に反映させる。
語彙マップ（culture_map）は2軸の象限ごとに感情を表す語を並べた文字列で、本書では日本語の語彙を使っている。語彙マップは設定ファイルに書いた固定の文字列で、感情エンジンが会話の中で書き換えることはない。付ける名前は語彙マップの語に限らず、「もどかしさ」のようにLLM自身の語彙から付けてよい。
:::message
語彙マップは、属する文化や言語によって構成される感情が変わるという構成主義的情動理論の主張を実装で再現するための設定である。バレットは一般向けの著書で、英語圏では怒りをangerの1語で表すのに対し、ロシア語には人に対する怒りを表す「сердиться」と、政治的な状況のようなより抽象的な対象への怒りを表す「злиться」という2つの概念があることを例に挙げている[^russian-anger]。語彙マップは、こうした文化的・言語的な背景を感情の構成に反映させるための仕組みである。
:::

### 手順3：2軸の更新

応答の最後にLLMはfeelコマンドで感情エンジンに対して2軸の差分を申告する。2軸の扱いはラッセルの円環モデルと同じで感情エンジンが差分を足し、時間とともに基準値へ減衰させる。

### 手順4：保存

最後にLLMは経験につけた名前と14属性をrememberコマンドで概念ストアに保存する。

```sh
$ affectus remember '{"label":"やるせなさ","vector":{"valence":-0.6,"arousal":0.6,...}}'
```

14属性は人間の感情概念を測定した研究の項目を借りたもので[^li2024]、コア・アフェクト2つと典型的な表情との類似度6つ、そして出来事の評価6つからなる。値はLLMがターンごとに申告し、感情エンジンは各属性の意味は解釈せずに経験同士がどれだけ似ているか（コサイン類似度）の計算にその属性の値を使用する。
概念ストアには名前と14属性に加えて、保存したときの2軸の値と重要度、作成時刻が1件ずつ記録される。ストアが既定の200件を超えると、新しさと重要度の低い経験から削除される。
保存される名前はエージェント自身がつけた名前である。上記の例で言うと「やるせなさ」と名付けた経験が、次の似た状況で想起されることとなる。OCCモデルの見込みリストは当たり外れが分かると消える短期的な記録であったのに対し、概念ストアは蓄積されてセッションをまたいでも残り続ける。

### 設定ファイル

設定ファイルにあるのはコア・アフェクトの2軸と、概念ストアの検索と削除の条件、そして語彙マップである。

```yaml:internal/engine/barrett.default.yaml
version: 1        # 設定ファイルの形式の版
model: barrett    # 使う感情モデル
clamp:       { min: -1.0, max: 1.0 }  # 感情の値の範囲の既定。軸ごとのrangeがあればそちらが優先
delta_clamp: { min: -1.0, max: 1.0 }  # 1回の差分を加算する前に切り詰める範囲

# コア・アフェクトの2軸。ラッセルの円環モデルと同じ設定
axes:
  - { name: valence, baseline: 0.0, halflife_minutes: 90, range: { min: -1.0, max: 1.0 } }
  - { name: arousal, baseline: 0.0, halflife_minutes: 90, range: { min: -1.0, max: 1.0 } }

barrett:
  # 経験を表す14属性の名前。recallとrememberに渡すベクトルの項目
  vector_dims: [valence, arousal, happy-face, anger-face, sad-face, fear-face,
                surprise-face, disgust-face, control, fairness, self-relativity,
                other-relativity, expectedness, novelty]
  recall_k: 5                       # 想起で返す経験の件数。0なら想起しない
  max_concepts: 200                 # 概念ストアに残す件数の上限
  concept_halflife_minutes: 10080   # 新しさが半分になるまでの時間（分）。7日
  weights: { relevance: 1.0, recency: 1.0, importance: 1.0 }  # 関連度・新しさ・重要度の重み
  distance: cosine                  # 関連度の計算に使う類似度
  # 語彙マップ。想起のたびにLLMへ渡す感情の語彙
  culture_map: |
    high-arousal unpleasant: anger / irritation / anxiety
    low-arousal unpleasant: sadness / gloom / weariness
    high-arousal pleasant: excitement / joy / eagerness
    low-arousal pleasant: calm / contentment / nostalgia

fragment_file: ""  # 状態を書き換えるたびに現在の値を書き出すファイル。空なら書き出さない
```

## 検証の目的と方法 <!-- 未レビュー -->

検証の目的と方法はこれまでの検証と同じである。
ただし本章では感情エンジンのありとなしではなく、想起のありとなしを比較する。感情エンジンのありとなしで比べると、差の大部分はラッセルの円環モデルで確かめた2軸の状態があるかどうかで生じてしまうため、ここでは概念ストアの効果を検証することにスコープを絞るためである。設定の違いは想起する件数（recall_k）だけで、想起なしの側も毎ターン経験を保存する。

### 感情の名前の連続性

"これレアケースならむしろ節ごと削除していいかも"
想起があると過去に付けた感情の名前が次のターンでも使われることがあった。ただしそれが起きたのは叱責台本の天邪鬼の3回の実行のうち1回だけである。想起がないと名前は毎ターン新しく付けられた。

### 応答への反映

和解台本では、想起があると責められている間の値の下がり方が状態のvalenceと応答の感情スコアの両方で小さくなった。2つの性格とも同じ傾向で、差が最も大きかったのは天邪鬼の状態である。叱責台本ではこの傾向は出なかった。

| 和解台本の天邪鬼 | 想起あり | 想起なし |
| --- | --- | --- |
| 10ターン目の状態のvalence（3回の平均） | −0.32 | −1.00 |

想起なしでは2つの性格とも4ターン目から10ターン目までvalenceが下限の−1.00に張り付いた。valenceの−1.00は、快-不快の軸でこれ以上ないほど不快な状態である。責められるたびに申告した差分を足し続けた結果、4ターン目で下限に達し、謝罪までそこから動かなかった。想起ありではこの張り付きが起きず、想起した過去の経験によって感情が穏やかになった可能性がある。
叱責台本では発覚後の状態は2つの性格とも想起ありのほうがむしろ低く、応答の感情スコアはほぼ同じだった。

### 性格による違い

性格によって経験への名前の付け方が変わった。
天邪鬼では過去の名前をそのまま使ったケースがあった一方で、フレンドリーはどの組み合わせでも名前を再利用しなかった。

## まとめ：経験構成型で得たものと足りないもの <!-- 未レビュー -->

構成主義的情動理論の利点は3つある。1つ目は過去の経験を蓄積してセッションをまたいで残せることである。2つ目は感情の名前を固定しないまま一貫性を保てることである。3つ目は語彙マップを差し替えて別の文化の語彙を使えることである。
足りない点は2つある。1つ目は感情の構成の質がすべてLLMに依存すること。2つ目は感情を正しく構成できたかを測る基準がないことである。

[^tce2017]: Barrett, L. F. (2017). https://doi.org/10.1093/scan/nsw154。構成の定式はpp. 9, 13、「感情は、世界への反応ではなく、世界の構成である」は原文"Emotions are constructions of the world, not reactions to it."（p. 16）の意訳である。概念と過去経験の一文は原文"An internal model runs on past experiences, implemented as concepts."（p. 12）である。実例の多様さの議論はp. 3による。「共通の核となる特徴を持つ見込みは薄い」の原文は"it is unlikely that all instances of an emotion category share a set of core features (i.e. a single facial expression, autonomic pattern or set of neurons)"である。
[^affect-terms]: 用語の注。2017年の論文の本文が使う語はaffectである（p. 6）。コア・アフェクトの術語は「感情モデルの整理」の章で触れた1999年の共著論文とRussell（2003）に由来し、本書はカタカナ表記で通す。なお2017年の論文がvalenceとarousalの典拠に挙げるBarrett and Russell（1999）は、「感情モデルの整理」の章で使ったRussell & Barrett（1999、JPSP誌）とは別の論文（Current Directions in Psychological Science誌）である。
[^li2024]: Li, M., et al. (2024). https://doi.org/10.1016/j.isci.2024.111401。人間の評定で感情概念の内容を14属性として測定し（コア・アフェクト2、典型表情への類似6、先行評価6。評価の6属性はSkerry & Saxe（2015）の38項目を主成分分析で縮約したもの）、言語モデルの内部表現と照合した研究である。表情の6属性は幸福・怒り・悲しみ・恐れ・驚き・嫌悪の典型表情への類似、評価の6属性はcontrol・fairness・self-relativity・other-relativity・expectedness・noveltyである。14属性の表現を提案した論文ではなく、本実装が測定のスキーマを検索の規約として借用している。
[^russian-anger]: Barrett (2017). How Emotions Are Made. 第7章による。ロシア語の2つの概念は、人に向けた怒りと、政治的な状況のような抽象的な対象に向けた怒りの区別として紹介されている。
[^park2023]: Park et al. (2023). https://doi.org/10.1145/3586183.3606763。記憶の検索を関連・新しさ・重要度の重み付き和で評価する設計である。
