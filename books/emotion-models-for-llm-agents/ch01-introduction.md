## はじめに

AIエージェントやAIキャラクターに感情らしい振る舞いをさせたいとき、最も手軽なのはシステムプロンプトに性格や感情を書く方法です。たしかに多くの場合はそれで十分ですが、会話をしているとそれだけではどうにも空虚な感じがしてきます。結局はコンテキストやプロンプトからもっともらしい感情表現らしきものをしているだけにすぎず、セッションが変わればそれらの感情もまっさらなところに立ち返ってしまうからです。

こうした空虚さや不自然さを軽減したいと考えたのが感情エンジンの個人開発のきっかけでした。"ここまで書いた。"

感情の状態をどこに置けばセッションをまたいで残せるか、感情を何個の数値で表すか、時間が経ったら感情をどう変えるかを決める必要があります。本書はこれらを決める手がかりとして感情心理学の理論を使います。

本書の方法は、感情の状態をLLMの外側に置き、感情心理学の理論に沿って設計することです。外側に置いた状態は感情エンジンが保持して時間とともに減衰させ、LLMはその状態を読んで応答に反映させます。理論が変わると外部状態に持たせるものも変わるので、本書では4つの理論を実際に実装し、同じ条件で検証して比べます。

## 想定読者 <!-- 未レビュー -->

主な読者として、LLMエージェントやAIキャラクターを開発していて、感情表現をプロンプトでの演技以上のものにしたいエンジニアを想定しています。感情心理学の知識は前提にしません。理論は第2章から順に説明します。

感情の理論とそのAIへの応用に興味がある方にも読めるように書いています。実装の章にはコードやコマンドが出てきますが、理論と設計の章だけでも本書の考え方は分かるようにしています。

## 本書の位置づけ <!-- 未レビュー -->

本書を読み進める前に、3つのことを断っておきます。

1つ目は、プロンプトで感情を演じさせる方法を否定するものではないことです。どこを不自然と感じるかは人によって違い、プロンプトだけで十分な場面も多くあります。本書はプロンプトの外で感情を扱う方法の1つを示すものです。

2つ目は、本書の4つの系統は筆者が実装のために整理したもので、感情心理学の標準的な分類ではないことです。代表として選んだモデルも、実装のしやすさと筆者の関心で選んでいます。

3つ目は、感情の状態をLLMの外に数値で持つ設計は本書の発想ではないことです。この設計はLLMが登場する前から感情を扱う計算技術の研究で積み上げられてきたもので、LLMを使った先行研究もあります。第3章でそれらを紹介します。本書の実装は筆者が作ったaffectusというOSSで、最初に試すための初歩的な一例として示します。

## 本書の構成 <!-- 未レビュー -->

本書は次の8章で構成されています。

| 章 | 内容 |
| --- | --- |
| 第1章 導入 | 本書が扱う問題と構成 |
| 第2章 感情モデルの整理 | 感情心理学の理論を4つの系統に整理する |
| 第3章 感情エンジンの設計 | 感情の状態をLLMの外側に置く感情エンジンの設計とLLMとの役割分担 |
| 第4章 プルチックの輪を実装する | 8つの感情の量を持つモデルの実装と検証 |
| 第5章 ラッセルの円環を実装する | 2つの軸の値だけを持つモデルの実装と検証 |
| 第6章 OCCモデルを実装する | 出来事の評価から感情を導くモデルの実装と検証 |
| 第7章 構成主義的情動理論を実装する | 過去の経験から感情を作るモデルの実装と検証 |
| 第8章 比較とまとめ | 4つのモデルの比較と本書のまとめ |

第2章と第3章で理論と設計の考え方を整理し、第4章から第7章で1章に1つずつ理論を実装して検証します。第4章から第7章は同じ流れで進むので、興味のあるモデルの章から読むこともできます。その場合も第4章の「検証の目的と方法」だけは先に読んでおくと、検証の条件が分かります。
