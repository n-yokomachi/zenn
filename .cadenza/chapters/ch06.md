## Phase 3: Storyboarding (✅ Done 2026-08-16)

### 章の役割と建て付け

モデル章の3本目。評価導出型（代表: OCC モデル、Ortony, Clore & Collins 1988）を理論→外部状態→実装→実測で1周する。ch4・ch5 と同じ章型を踏襲。

- **章の主題候補: 「外部状態が初めて『なぜ』を覚える」**。ch5 の締め（「なぜそう感じたか——出来事の評価——を外部状態の側に置く方向。それが次章で扱う評価導出型」⚠ 執筆時現物照合）の正面回収。2つの新奇点を1本の筋にする:
  1. **申告の対象が変わる**: LLM は感情を申告しない。出来事への評価（desirability 等）だけを申告し、感情は決定論のルール表が導出する。ch3 の分業（保持・演算=決定論／解釈・命名=LLM）のうち、**感情の導出が決定論の側へ移る**——ch4・ch5 と逆向きの境界移動。ただし解釈の仕事は消えておらず、評価という一段手前に移っただけ（desirability の見積もりは解釈そのもの）
  2. **外部状態に出来事が入る**: 見込み台帳（prospect ledger）。「PRがマージされそう」のような**自然言語の label が、数値だけだった外部状態に初めて入る**（ch3「状態は数値のまま LLM に渡し」との緊張を正面から扱う⚠ ch3 逐語は執筆時照合）
- **ch5 節6 の直接回収**: 「侵害への怒りなのか、脅威への恐れなのか」——OCC では怒りの定義自体が評価の構造（望ましくない結果 × 非難に値する他者の行為の共起）で書かれる。区別が外部状態の側に戻る
- **ch3 の伏線回収**: ch3 節5 が既に見込み感情を予告済み（「望ましい出来事を見込めば希望が…安堵を導くには『何を恐れていたのか』が要ります」113行目付近・脚注 [^occ-prospect]）。ch6 は「第3章で予告した」と受ける
- **名前の帰還**: ch5 で外部状態から消えた感情の名前が、22個になって戻ってくる。ただし書き込むのは LLM ではなくエンジン——リードの引き候補
- ⚠ ch7 温存: 「評価から導く枠組み自体が感情カテゴリーの実在を前提にする」という限界の指摘は節6 の橋の1文まで。バレットの中身（構成・概念・予測）は書かない。⚠ ch8 温存: モデル間比較は定性まで

### 節構成（仮・6節＋リード。分量は骨子で確定。見込み 7,000〜7,500字）

**リード（約250字）**
- ch5 の締め（なぜを外部状態に置く方向）を受ける。この章は評価導出型、代表は OCC モデル
- 引き候補: 「感情の名前が22個になって外部状態へ戻ってくる。ただし、その値を書き込むのは LLM ではない」

**節1 OCC — 出来事・行為・対象への評価（約1,100字）＋図1**
- 1988年の共著書。ch2 の評価の立場の定義（意味づけから生じる）を受ける1文
- 理論の骨格: 感情は「出来事の結果」「行為」「対象の性質」への評価反応として3分岐し、条件を細かくすると22のタイプに分かれる（⚠ 分岐構造・22という数・各タイプの定義は**原典で照合してから確定**。現状は実装と二次情報ベース）
- 感情の定義が評価の構造で与えられることを、怒り（望ましくない結果 × 他者の非難に値する行為）を例に。ch2 の「if-then の形で書ける」の回収
- 見込み系列（希望→当たれば/外れれば別の感情）は ch3 の予告を受ける形で簡潔に
- ⚠ 書かないもの: 強度変数の全リスト・Scherer 等ほかの評価理論・EMA 等計算モデル史
- 図1: 3分岐→22タイプの構造図（原著の図の再構成。頁・図番号は Verification 1 で特定）

**節2 外部状態に落とす — 4つの問いへの OCC の答え（約1,000字）＋表1**
- 表1: 状態=22の感情の量＋**見込み台帳**／時間=更新時刻／更新の規則=**評価からの導出**（差分の加算の前に決定論の段が入る）／基準と戻り方=全軸 0 へ半減期（**台帳エントリは減衰しない**⚠）
- 名前の帰還を1〜2文（ch5 との対比。8→2→22 で最多。ただし節4 への布石: 書き込み手が違う）
- 外部状態の構成要素が初めて増えた（ch3 の表の「評価の対象の記録」の実体）

**節3 エンジンの中身 — 評価を受け取り、感情を導く（約1,100字）＋コード2つ＋図2**
- appraise の入力（4セクション・値域を最小限で。全文スキーマは書かない）。コード: appraise JSON 例1つ＋show の出力例（台帳付き1行 JSON）
- 導出ルールの見せ方: 8ルールの表を出すか、代表3つ（well-being / prospect / 複合）を文で書くかは骨子で確定。gains は「理論にない数字は今回も実装の選択」の線で1文（ch4・ch5 の線の継続）
- 複合の加算: anger の事象では distress と reproach も上がる（OCC の複合=共起の定式化に忠実。⚠ 原典照合）
- 図2: 会話ループに導出の1段が入った図（ch4 の2ループ図の変奏。appraise → DeriveDeltas → 加算・減衰）
- feel も残っている（汎用機構。対照実験のスイッチ）を1文——節5 への布石

**節4 外部状態が「なぜ」を覚える（約1,300字・主節）**
- ch5 節6 の回収から入る: 怒りと恐れの区別。OCC では区別が評価の構造として外部状態の側に書かれる（怒り=distress×reproach の共起、恐れ=見込みの負）
- 見込み台帳: 「何を恐れていたのか」が label ごと残る。**数値だけだった外部状態に、初めて自然言語が入る**。ch3 の「数値のまま渡す」の設計線がここで一箇所破れる——なぜ破ってよいか（label は感情の解釈ではなく出来事の記録。解釈の余地を固定しない）を正面から書く
- スニペットの「申告した記憶が残っていなくても、台帳を見て resolve せよ」——セッションをまたいで「なぜ」が生き残る、外部状態ならではの動き
- 境界の逆流: ch4 は関係を演算に入れないことを選び、ch5 は命名を丸ごと LLM に渡した。OCC は逆に、導出を決定論に固定する。ただし固定されたのは「評価→感情」の後半で、**「出来事→評価」の前半は依然 LLM の解釈**。境界の線は消えたのではなく一段手前に引き直された
- ch3 の Bhattacharyya 注の回収候補: 評価の質を測る足場が、評価導出型では「申告された評価そのもの」として外部状態に残る
- ⚠ ch7 伏線は一言だけ（22という粒度・カテゴリーの前提には触れず、節6 に譲る）

**節5 実測 — 評価の申告は会話でどう動くか（約1,700字）＋図3**
- リグの OCC 対応（Required verification 3）のうえ、**同一2台本×2性格×on/off×N=3**（比較可能性のため台本は変えない）
- 読みどころ候補（分析後に骨子で確定）: (1) 和解台本の叱責で anger 事象の複合（distress+reproach+anger の同時上昇）が見えるか (2) **見込みの発行と決着が自然に起きるか**（叱責中に「誤解が解けるかも」の hope が発行され、t11 の謝罪で resolve されたら見事な回収——起きるかどうか自体が観察対象） (3) 22軸中どの軸が動くか・性格差
- 応答側: 極性の on/off 比較（ch4・ch5 と同型）＋⚠ モデル間は定性まで
- 22軸の図の形式は分析フェーズで確定（8軸スモールマルチプルの流用不可。動いた軸のみ・バーチャート等の案）
- 留保は ch4・ch5 と同型＋「評価の質は測っていない」（appraise の値が妥当かは別問題）

**節6 評価導出型で得たもの、足りないもの（約700字）**
- 得たもの: なぜの記録（会話ログ以外で初めて）／導出の再現性（同じ評価なら同じ感情。申告のぶれが感情のぶれに直結しない）／時間の構造（見込み→決着という感情の物語性）
- 足りないもの: (1) 評価の質は結局 LLM 次第——境界が一段手前に移っただけで、解釈の不安定さは消えていない（ch3 の懸念の再確認） (2) 22のタイプと導出ルールの固定——**評価から感情を導くという枠組み自体が、感情のカテゴリーが評価に先立って実在することを前提にしている**
- 橋: そのカテゴリー自体が構成されたものだとしたら——次章の経験構成型（バレット）へ。⚠ 中身は先取りしない
- ⚠ ch8 温存に触れない
