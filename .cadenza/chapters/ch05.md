## Phase 3: Storyboarding (✅ Done 2026-08-10)

### 章の役割と建て付け

モデル章の2本目。次元パラメーター型（代表: ラッセルの円環モデル、1980）を理論→外部状態→実装→実測で1周する。ch4 と同じ章型を踏襲し、対比で差分を立てる。

- **章の主題候補: 「円環は外部状態に書かれない」**。プルチックは関係構造（輪）を、対極の宣言と軸の並び順で設定に書き込んだ。ラッセルの円環モデルでは、外部状態は2軸の平面だけで、円環はどこにも現れない。円環は「状態がよく分布する形」という理論の主張であって、外部状態の制約ではない——という対比が ch4 節4 と対になる主節を作る
- **ch4 の橋の回収**: 「名前を最初から外部状態に置かない」（ch4 現行本文の逐語）。感情の名前が外部状態から消え、命名の責務が完全に LLM へ移る（ch3 節7 の「いちばん LLM 寄り」の実地）
- **新要素: 基準値が非ゼロ**（arousal の baseline 0.3＝安静時覚醒）。ch3 の4つ目の問い「基準と戻り方」の答えが初めて「ゼロ＝無感情」でなくなる。「落ち着いた状態は無ではない」を外部状態が表現する
- **実測は Russell 版を新規実施**（state.md のオーナー確定事項）。直接型2台本・2性格・on/off・N=3 の同一設計で、ch4 との条件差はモデル設定のみにする。**リグの Russell 対応が必要**（下記 Required verification 3）
- ⚠ ch8 温存: 「Barrett の core affect は次元型の中身」を書かない。core affect の語は ch2 公開範囲（1999 の定義・系譜）でのみ使用。1999/2003 の理論の深掘りは ch7 の領分

### 実装・実測の一次資料（affectus。2026-08-10 に直読で確認済み）

- `internal/engine/russell.default.yaml`: 2軸。valence（baseline 0.0・range −1.0〜1.0）／arousal（**baseline 0.3**・range 0.0〜1.0）。halflife 90分。opposite 宣言なし
- `config.go` の Range フィールド: 軸ごとのレンジ上書き（「models with asymmetric axis domains」のためのもの。Russell が使用者）。`apply.go` の axisClamp が適用

- 設計書: `docs/superpowers/specs/2026-05-30-russell-circumplex-design.md`（分析フェーズで精読）

### 節構成（仮・6節＋リード。分量は骨子で確定。ch4 実績から本文6,500〜7,000字を見込む）

**リード（250字）**
- ch4 の締めからの受け（名前を捨てる方向）。この章は次元パラメーター型＝ラッセルの円環モデル

**節1 円環モデル — 2つの軸と、その上の円（1,000字）**
- 1980年の主張: 感情状態は快-不快と覚醒の2次元双極空間の円として最もよく表される（逐語は ch2 V3 の記録から）
- 8つの概念の円順序（pleasure 0°〜relaxation 315°）。図1
- **valence の語の受け**: 「第3章で触れたとおり」の1文（原典の語は pleasure-displeasure。呼称は後年の定着）
- ラッセル自身の後年の移動（1999・2003）は ch2 参照の1文にとどめる
- ⚠ 基本感情説の「否定者」として書かない（原典は対立仮説として位置づけるまで。ch2 V3）
- 書かないもの: スケーリング手法の数理・PAD・1999/2003 の中身

**節2 外部状態に落とす — 4つの問いへのラッセルの答え（1,000字）**
- 表1: 状態＝2軸の値のみ（**感情の名前が外部状態から消える**）／時間＝更新時刻／更新の規則＝差分の加算／基準と戻り方＝**valence 0.0・arousal 0.3 へ**半減期で減衰
- 新要素を2つ立てる: (1) 外部状態がプルチックの1/4になった（8軸+宣言 → 2軸）(2) **基準が非ゼロ**——「落ち着いた状態」は無感情ではなく、静かな覚醒がある状態。理論の resting state を baseline が写す
- ⚠ ch4 で立てた「理論が決めるのは1つ目の中身だけ」の線は維持しつつ、baseline 0.3 が「理論の含意を実装が解釈した値」である旨を正確に（0.3 という数値自体は理論にない）

**節3 エンジンの中身 — 同じエンジン、違う設定（900字）**
- YAML 全文（短い。2軸・非対称レンジ・baseline 0.3）。**エンジンは ch4 と同一**で、変わったのは設定だけ——「モデルの差し替え＝設定の差し替え」を見せる（本書の設計の再利用性が最初に効いてくる場面）
- 非対称レンジ: valence は双極（−1〜+1）、arousal は量（0〜1）。外部状態の形が理論の主張（快不快は両極、覚醒は多寡）を写している
- show/feel/tick は同じ。コマンド例1つ（{"valence":0.40,"arousal":0.55} の形）
- 書かないもの: ch4 と同じ2ループ図の再掲（本文参照で足りる）

**節4 円環は外部状態に書かれない（1,100字・主節）**
- プルチックとの対比で立てる: ch4 は関係（輪）を宣言と並びで設定に書いた。ラッセルの外部状態には円環がどこにもない。平面があるだけ
- 円環は理論の主張（状態の分布の形）であって、外部状態の制約ではない。実装も円周への射影や制約を入れていない。中心付近（どっちつかずの弱い状態）も、円の外周も、平面上の点として等しく持てる
- **命名の完全な移譲**: スニペットは象限の例語は渡すが、名前を確定しない。「高覚醒・快」の点を興奮と呼ぶか高揚と呼ぶかは、毎回 LLM が文脈で決める。ch3 節7 の「いちばん LLM 寄りの境界」の実地
- ch4 の両価（対極の同時活性）はこの外部状態では**表現できない**ことを正直に書く（valence は1本の双極軸なので、嬉しさと寂しさの同居は「0 付近」に潰れる。ほろ苦さの置き場が今度は外部状態の側で消えた）——ch4 の「潰す方向に働く」の議論が、軸の設計自体に現れる例。⚠ ラッセル 1980 自身が双極性を主張している（理論に忠実な結果である旨を明記）
- ⚠ ch6 への伏線: 「なぜ快が下がったのか」の記録もこの外部状態にはない（一言だけ。深掘りは節6）

**節5 実測 — 2軸は会話でどう動くか（1,600字）**
- 同一設計（直接型2台本×2性格×on/off×N=3・SDK・Comprehend）。**ch4 と違うのはモデル設定だけ**と明示
- 見せ場: **valence-arousal 平面上の軌跡図**（和解台本 friendly-on。責められて低快へ沈み、謝罪で右上へ戻る弧が見えるか——結果次第で記述）
- **状態の valence と応答の極性の直接比較**（プルチックではできなかった芸当。外部状態の軸と判定器の軸が同じ意味を持つため、状態が言葉に透けるかを軸同士で突き合わせられる）
- 留保は ch4 と同型＋「結果次第で記述を調整」（実測前のため、この節の詳細は分析フェーズ後に骨子で確定）
- ⚠ 実測結果が仮説（弧・沈み・戻り）と違ったら、そのまま正直に書く

**節6 次元パラメーター型で得たもの、足りないもの（700字）**
- 得たもの: 最小の外部状態。軸にない気分の置き場問題（ch4 節6）への部分的な応答——名前が固定されないので、懐かしさも「平面上のこのあたり」としては持てる。ただし…
- 足りないもの: (1) 双極軸ゆえに両価は潰れる（節4 から回収）(2) **出来事の記録がない**——同じ valence −0.5 でも、悲しみ（喪失）と怒り（侵害）の区別が外部状態にない。何があってこの位置に来たのかを外部状態が覚えていない
- 橋: 出来事の側、つまり「なぜそう感じたか」を外部状態に置く方向がある（ch6 評価導出型）
- ⚠ ch8 温存に触れない
