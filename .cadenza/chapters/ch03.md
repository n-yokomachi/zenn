### ⚠ 節構成を改訂した（2026-07-28・Verification 6 を受けて）

先行研究の調査で、**本章が論じる設計が新規ではないことが判明した**（詳細は Verification 6）。「感情状態を外部に数値で保持し決定論的に減衰させる」は affective computing が1990年代末から積み上げてきた標準的なパラダイムであり、LLM エージェントへの適用も2023〜2025年に複数の先行研究がある。

**これを隠して書くと不誠実になる。同時に、隠さず書くほうが章として強くなる。** 筆者が考えた設計ではなく、系譜のある設計パターンとして提示し、そのうえで**解釈と言語化の層が LLM になったことで何が変わったのか**を本章の主題に据える。従来この層はテンプレート・規則・アニメーションが担っていた。そこが生の数値を文脈に応じて解釈できるものに置き換わったことが、実際に新しい点である。

### 節構成（7節・目標 8,500字）

**節1 プロンプトで演技させたときに足りないもの（900字）**
- 役割: ch1・ch2 から受けて、この章が扱う問題を定位する
- **⚠ 冒頭で「この章にコードがない」ことを読者と約束する（読者体験レビューの最優先指摘）**: 章タイトルが「実装するには」なので、主層は手を動かす内容を期待して開く。抽象論が退屈になる最大の要因は抽象性そのものではなく期待とのずれ。「この章で決めるのは何をどこに置くか。実際に作るのは第4章から」を1段落で置く。ch2 が冒頭で「4区分は筆者が実装の都合で切ったもの」と先に断ったのと同じ型。これがあるとコード不在は「まだ書かない」という合意に変わる
- ⚠ **演技指示を否定しない**（本書全体の位置づけ）。「それでよい人もいる」という留保を守る
- 足りないのは時間。文脈が切れれば状態は消え、同じ話題に戻っても前の気分は続かない
- ⚠ 不自然さの感覚は主観であると明記する
- 締め: では感情を持続させるとは、何を作ることなのか

**節2 LLM の内側に感情はあるのか（1,400字）**
- **⚠ 過積載の恐れが両レビューで指摘された。下書き実測の第一候補**。載せる想定が多すぎる（5件の収束・局所性の知見・逐語引用2箇所・二分法から降りる展開・valence/arousal の呼称注記・用語規律）。**精度が命の節なので、圧縮して曖昧になるのが最悪のシナリオ**。1,100字から1,400字に増やしたうえで、なお実測で確かめる
- **⚠ 5件の収束は研究名を列挙しない**。「複数の独立した研究が同じ方向に収束している」の1文と、代表1件（Anthropic 2026）の深掘りに絞る（writing-guide の網羅的リスト回避）
- **⚠ 逐語引用は主役を1本に絞る**。「持続的に符号化された内部状態とは限らない」の対比を主役にし、二分法から降りる一文は地の文の要約と短い引用句にとどめる
- **⚠ 副層向けの用語の橋を必ず架ける**。トークン位置・文脈 window・attention は初出時に1句のカッコ補足で足りる（例: 文脈 window（モデルが一度に読める範囲））
- 役割: 外に置くという判断の前に、内側で何が分かっているかを正確に押さえる
- **書けること（6件中5件が独立に収束）**: LLM 内部には valence/arousal 軸を持つ構造化された感情概念の表現が存在し、出力に因果的に影響する
- ⚠⚠ **「LLM は持続的な感情状態を持てない」と書かない**。Anthropic 2026 の原文が attention による文脈 window 内の追跡を認めており、そう書くと原典と矛盾する誤読になる
- ⚠ **Tosato 2026 を感情状態の根拠に使わない**。測定対象は personality trait であって emotion state ではない。引くなら「人格特性の測定の不安定性」という別テーマだと明示する。**使わない選択も可**
- 書ける線: 表現が機能する範囲はトークン位置と文脈 window の内側であり、**文脈 window を超えた永続化を扱った研究は、筆者が参照した範囲には見当たらない**。かつ開発者が状態として読み書きできる形にはなっていない
- **⚠⚠ 「ターンを跨いだ」と書かない（事実正確性レビュー）**: 複数のターンは通常は同一の文脈 window の内側にあり、window 内なら Anthropic 2026 自身が attention による実効的な追跡を認めている。**この節で引く当の引用と自己矛盾する**。**「文脈 window を超えた」「セッションを跨いだ」に限定すること**
- **⚠ 不在の主張には限定を付ける**: 検証の根拠は Verification 1 の6件と Anthropic 論文内の全文検索であり、悉皆調査ではない。「筆者が参照した範囲では」を必ず添える
- **この節の山場（Verification 2 で確定した使い方）**: 著者ら自身が人間の感情の持続と自分たちの観測を対比している。「会話を通じて一貫して見える応答は、各生成ステップで似た概念が繰り返し活性化した結果かもしれず、持続的に符号化された内部状態とは限らない」。**これは筆者の解釈ではなく原著者の記述**なので、そう明示して引く
- **二分法から降りる一文を置く**: 著者らは "intuitions that persistence is a key property of emotional states may be inappropriate in the context of transformer-based models" とも書いている。**「持てる／持てない」を争点にしないという本章の姿勢は、原著の姿勢でもある**。ここを通ると節3 の「どこに置くか」へ自然に移れる
- 締め: 問題は持てるかどうかではなく、どこに置けばいつ誰が読み書きできるか

**節3 外に置くなら、何を置くことになるか（1,300字）**
- 役割: 外部化が筆者の判断であることを引き受けたうえで、理論が何であっても必要になる「器」を抽出する。この章で最も一般性が高い部分

- **⚠⚠ 冒頭に「外部化は設計判断である」と宣言するブロックを置く（論理構成レビューの最優先指摘）**: 「外部化は文献からの帰結ではなく筆者の設計判断として提示する」と Phase 3 で決めているのに、**その判断を実際に引き受ける仕事がどの節にも割り当てられていなかった**。節2 は問いの言い換えで終わり、節3 は「なら」で条件化したまま器の抽出に入るため、章の最重要決定が一度も明示されないまま既成事実化する
  - 根拠は節2 で確定済みの2点で足りる。開発者が状態として読み書きできる形になっていないこと、セッションを跨いだ永続化が先行研究の空白であること
  - **「事実→判断」であって「事実→帰結」ではないと書き分ける**
  - 選ばなかった側にも一文触れると判断の輪郭が立つ。内部表現への介入は研究段階であり、API 経由の利用では手が届かない。⚠ 一文にとどめれば Skipped verification の「内部表現の技術的詳細に踏み込まない」と両立する

- 器の4点（執筆時に精査する）
  - 状態そのもの（いま何がどれだけか）
  - 時間（いつの状態か）
  - 更新の規則（出来事によってどう変わるか）
  - 基準と戻り方（何もしなければどこへ向かうか）
- **⚠ 4点は「構成要素」ではなく「答えるべき問い」として立てる**。そうすれば「減衰させない」も『基準と戻り方』への一つの答えとして扱える
- **⚠ 更新の規則と基準・戻り方の重なりを断つ定義を置く**。前者は出来事による変化、後者は時間による変化。この区別が節5 の「二つの契機」で再登場するので、4点が羅列ではなく設計として見えるようになる
- **⚠ 各項目に「欠けると何が壊れるか」を1文ずつ添える（読者体験レビュー）**。定義だけ並べると主層には自明、副層には抽象的で、双方に「で？」が起きる。**コードなしで具体性を出す唯一の手段はシナリオ**。例として時間の項目なら、3時間後に戻ってきた相手に対して3時間前の怒りを全強度のまま向けている場面
- ⚠ **特定の実装のデータ構造を出さない**。抽象度を保つ
- **⚠⚠ 「LLM が持てないもの」と書かない（論理構成レビュー・ch2 事故録の「未検証の主張が形を変えて生き残る」型）**: 節2 で「持てる／持てない」を争点にしないと決めた直後にこの語を使うと先祖返りになる。**精密化する**——LLM に欠けているのは「持つこと」ではなく、**リクエストとリクエストの間に時間が流れること**。推論が走っていない間は何の計算も起きないので、「何もしなくても進む変化」の担い手が内側に存在しない。この形なら節2 と矛盾せず、節5 の第二の契機への伏線にもなる
- **⚠ 「この設計には系譜がある（節6 で扱う）」の前方参照を一文置く**。affective computing を知る読者が節3〜5 を新規性の暗黙主張と読む事故への保険

**節4 境界をどこに引くか（1,700字・主節）**
- **⚠ この節を断定で書き切る（読者体験レビューの重要指摘）**: 本章は7節中5節が留保で締まる設計になっており（節1 の主観性、節2 の断定回避、節5 の参照どまり、節6 の新規性否定）、そのままだと**読者は「結局この著者は何を主張しているのか」を掴めずに終わる**。抽象的な設計論で実装者を退屈させない最後の砦は著者の判断の手応えである。骨子の「免責で終わらせない」を執筆時の最優先で守る
- **⚠ 節の締めの文型を散らす**。節1・節2 とも問いで終わる設計になっている。全節が同じ型で終わると機械的に見える
- 役割: 本章の主節。決定論的な処理と LLM の判断の分界点を論じる
- 分業の原則: 保持・減衰・演算は決定論の側、解釈・命名・言語化は LLM の側
- **なぜその線なのか**を論じる。数値をどう感じるかは文脈依存の解釈であり、規則で決め打つと文脈を無視した挙動になる
- 境界を動かすと何が起きるかを抽象的に論じる。エンジン側が「強い喜び」のようなラベルを付け始めた時点で、それは解釈の混入である
- ⚠ **実装の失敗談を具体で書かない**（affectus の経緯は ch4〜ch7 か ch8 で扱う）。ここでは設計原則として述べる
- ⚠ この節が本章で唯一「筆者の判断」を厚く書ける場所。免責で終わらせない

**節5 状態はいつ、誰が更新するのか（900字）**
- 役割: 更新の契機と主体を整理する。**節4 が出力側の境界（状態から言葉へ）なら、この節は入力側の境界（出来事から状態の変化量へ）**
- **⚠ 節4 との関係を一行で明示する（論理構成レビュー）**: 読者が「節4 で線を引き終えたのに、また線の話が始まった」と感じる恐れがある。**出来事の評価は節4 の原則では決め打ちできない箇所**であり、演算でも言語化でもない第三の機能にあたる。だから得失の併記にとどめる、と書けば CoRE を参照どまりにする方針とも噛み合う
- 二種類の契機: 会話のターン（出来事による変化）と、時間経過（何もしなくても進む変化）。**節3 で立てた「更新の規則」と「基準と戻り方」の区別がここで再登場する**
- 更新の主体: 自己申告か、外部の評価器か。それぞれの得失
- **自己申告の弱点に触れるなら CoRE（Bhattacharyya ほか, arXiv:2508.05880）を参照**。LLM に評価推論をさせると人間の判断とずれ、文脈で不安定という知見。⚠ **「だから外部評価器が必須」という強い主張にしない**。「こうした懸念を指摘する研究がある」という参照どまり。⚠ プレプリントであること、および **v2 で改題している**ことに注意（v1 と v2 でタイトルが違う）
- ⚠ 抽象的なループの形にとどめる。特定のコマンドやフックの名前を出さない

**節6 この分業は新しくない（1,000字・2026-07-28 追加）**
- 役割: 本章がここまで論じた設計に系譜があることを示し、そのうえで**何が新しいのか**を正確に述べる
- **⚠ 「譲歩してから弁明」の順で書かない（読者体験レビュー）**: 「新しくない」を先に立てて後から価値を取り返す構成だと、読者は一度落胆してから回復を待つことになり、「では本書を読む意味は」が残る。**読者の利益の側から開く**——主層は自分の設計判断の裏づけを探して読んでいるので、系譜があることは欠点ではなく保険である。「ここまでの設計を筆者の発明として受け取る必要はない。系譜がある」の向きで書き出す
- **⚠ 締めで節4 の価値を事後的に証明する構造にする**: 「分業の境界そのものを主題にした研究は**筆者の調べた範囲では**ほとんど見当たらない。それが節4 で論じたことである」。**不在の主張なので「筆者の調べた範囲では」の限定を必ず付ける**（根拠はサブエージェント2体の調査であり悉皆ではない）
- 見出し「この分業は新しくない」自体は誠実さの信号として機能するので変えない
- ⚠ **この節を書かないと不誠実になる**。Verification 6 のとおり、この設計は affective computing が1990年代末から積み上げてきたもの
- 名前を挙げる先行研究（**均等に列挙しない。writing-guide の「網羅的なリストを避ける」に従い、深掘り1つ＋軽く数件**）
  - LLM 以前: 感情を数値で外部に保持し決定論的に減衰させる系譜。**ALMA（Gebhard 2005）を深掘りする**。感情・ムード・性格を時間スケールで分離している
  - LLM 以後: Generative Agents（Park ほか 2023）、Chain-of-Emotion（Croissant ほか 2024）、Dynamic Affective Memory Management（Lu & Li 2025）

- **⚠⚠ ALMA の書き方（事実正確性レビューで骨子の記述に誤りが見つかった箇所）**
  - **「減衰関数を数式で定義している」と書かない。原論文に減衰の数式はない**。本文にあるのは "The intensity of emotions underlies a natural decay, which can be configured by several decay functions." のみで、具体形は設定例の XML に `function="linear"` と出るだけ。ムード変化も文章と図による記述で閉形式の式はない
  - 正しい書き方の例: 「感情の強度は設定可能な減衰関数で決定論的に減衰し、ムードは性格から算出される既定値へ一定時間（論文の設定では20分）かけて復帰する」
  - **✅ 「本章の議論と構造がほぼ同型」は書いてよい**（レビュアーが論文全8頁を読んで判定）。**節3 の器4点すべてに対応物がある**。状態＝強度つきの活性感情と PAD 空間上の現在ムード／時間＝感情の減衰時間・ムード変化時間（通常10分）・復帰時間（20分）・500ms 周期の更新／更新の規則＝評価規則による感情生成とムード変化関数／基準と戻り方＝性格から算出される既定ムードと "the current mood has a tendency to slowly move back to the default mood"。**「基準と戻り方」まで揃っている点は骨子の想定以上に同型**
  - **⚠ ただし1点を必ず書き分ける**。ALMA では入力側の評価も決定論の規則であり、出力側も "All utterances of the virtual characters are scripted, but according to their current mood" とスクリプト済みの発話・表情の選択。**つまり ALMA は解釈と言語化の層まで全部決定論で、同型なのは状態管理の器の部分だけ**
  - **→ この差こそが節6 の主題と節4 の存在理由を支える**。担い手が変わったこと、そして**境界をどこに引くかという問い自体が ALMA では立たない**こと。ここを明示して書く
- **何が変わったのか（この節の結論であり、本章の主題）**: 従来この設計で解釈と言語化を担っていたのはテンプレート・規則・表情アニメーションだった。そこが、生の数値を文脈に応じて解釈できるものに置き換わった。**分業の形は同じで、片方の担い手の性質が変わった**
- ⚠ **「初めての試み」「新しいアプローチ」と書かない**。本書全体の位置づけ（断定・権威づけをしない）とも整合する
- ⚠ **本書の貢献を過小に書く必要もない**。Verification 6 のとおり「状態管理における分業の境界をどこに引くか」を主題化した研究はほとんど見当たらない。それが節4 の主題である

**節7 パラダイムで変わるもの、変わらないもの（1,300字）**

**LLM 以前の系譜（感情を数値で外部に保持し、決定論的に減衰させる）**
- **ALMA（Gebhard 2005）が本章の議論に最も近い**。感情（短期）・ムード（中期）・性格（長期）の3層を時間スケールで分離し、ムードを PAD 空間上の点として表現する。感情の強度は設定可能な減衰関数で決定論的に減衰し、ムードは性格から算出される既定値へ一定時間（論文の設定では20分）かけて復帰する。Gebhard, P. (2005). ALMA - A Layered Model of Affect. AAMAS'05, pp.29-36. doi:10.1145/1082473.1082478. 無料 PDF: https://alma.dfki.de/papers/aamas05.pdf
  > **⚠ 訂正（2026-07-28・Fable が論文全8頁を読んで判明）**: 旧記載「感情強度から複数の減衰関数で決定論的に更新する**数式を提示している**」は**誤り。原論文に減衰の数式はない**。本文にあるのは "The intensity of emotions underlies a natural decay, which can be configured by several decay functions." のみで、具体形は設定例の XML に `function="linear"` と出るだけ。論文中の数式は Mehrabian からの引用である Big Five から PAD への既定ムード写像と、ムード強度＝PAD ベクトルのノルムの2つで、いずれも減衰の式ではない
- WASABI（Becker-Asano 2008 / Becker-Asano & Wachsmuth 2010, AAMAS journal 20(1), 32-49, doi:10.1007/s10458-009-9094-9）。PAD 空間での感情の時間発展。学位論文が無料: https://becker-asano.de/Becker-Asano_WASABI_Thesis.pdf
- EMA（Marsella & Gratch 2009, Cognitive Systems Research 10(1), 70-90）。評価理論の計算モデル化
- FAtiMA（Dias & Paiva 2005, LNCS 3808, pp.127-140, doi:10.1007/11595014_13 ／ Modular 版 Dias, Mascarenhas & Paiva 2014, doi:10.1007/978-3-319-12973-0_3）。OCC ベースの評価規則をルールエンジンとして実装
- Soar の感情拡張（Marinier, Laird & Lewis 2009, Cognitive Systems Research 10(1), 48-69）。無料: https://public.websites.umich.edu/~rickl/pubs/marinier-laird-lewis-2008-cogsys.pdf

**LLM 以後の系譜（2023〜2025）**
- **Generative Agents（Park ほか 2023, UIST'23, doi:10.1145/3586183.3606763, arXiv:2304.03442）**。memory stream の決定論的な蓄積と、reflection による LLM の解釈を分離。本章の分業に構造的に最も近い
- **Chain-of-Emotion（Croissant, Frister, Schofield & McCall 2024, PLOS ONE 19(5), e0301033, doi:10.1371/journal.pone.0301033。完全無料）**。応答生成とは別の LLM 呼び出しで感情と理由を生成しメモリに蓄積。⚠ **ただし減衰は決定論的な数値演算ではなく LLM 生成テキストの蓄積に依存しており、本章の切り分けとは異なる。この違いは正確に書くこと**
- **Dynamic Affective Memory Management（Lu & Li 2025, arXiv:2510.27418）**。感情情報を外部ストレージに保持し、抽出・重み付け・時間減衰を外部システムが担い、LLM は応答戦略の判断のみを担当。**役割分担の記述が本章とほぼ一致する**。`../references/ch02-collected.md` セクション C の持ち越し4番と同一
- Emotional Cognitive Modeling Framework（Ma ほか 2025, arXiv:2510.13195）。PAD で状態を数式計算し、外部層が状態計算とメモリ管理、LLM 層は理由付けと行動選択。同持ち越し5番と同一

**外部化という潮流そのもの**

### Verification 4: 節7 の4区分対応を理論側の要請から導く 🟡（2026-07-28・要ファクトチェック）

**方針**: 対応は実装から逆算せず、**各理論が何を主張しているかから導く**。ch2 で確定した各系統の定義（Gendron & Barrett 2009 の逐語訳、次元型のみ Russell 1980）を出発点にする。

| 本書の呼称 | 理論の主張（ch2 で確定済み） | そこから要請される、外に置くもの |
|---|---|---|
| カテゴリーパラメーター型 | 生物学的に特権的な種類の感情が、対象や出来事によって自動的に引き起こされる | 感情の種類ごとの量。理論が感情どうしの関係を定めているなら、その関係も |
| 次元パラメーター型 | 感情状態は、快-不快と覚醒度という2つの軸が張る空間の中で、円環状に配置される位置として表せる | 少数の軸の値のみ。**感情の名前は外に置かれない** |
| 評価導出型 | 感情は反射的に引き起こされるだけのものではなく、個人が対象に与える意味づけから生じる | 感情の量に加えて、**評価の対象そのもの**と、評価から感情を導く規則 |
| 経験構成型 | 感情は、それ自体は感情に特化していない、より基本的な心理的材料から構成された心的な複合物である | 材料の層に加えて、**経験と概念の蓄積**（構成するための在庫） |

**導出のポイント（節7 の地の文で書く内容）**
- **次元パラメーター型が最小**。外部状態を見ても「これは怒りなのか悲しみなのか」は決まらない。名前づけは読み取る側の仕事になる。この型を選ぶことは、命名の責務を LLM に渡すことと同義
- **カテゴリーパラメーター型は関係構造の有無が理論に依存する**。⚠ 基本感情説すべてが感情どうしの関係を定めているわけではない（Plutchik の輪は定めているが、Ekman の基本感情は輪を持たない）。「カテゴリー型なら関係構造がある」と一般化しない
- **評価導出型では、感情の値のほかに出来事の側の記録が要る**。将来の見込みに関する感情は、その見込みが後で実現したか外れたかによって別の感情に変わる。したがって見込みそのものを覚えておかないと、後続の感情が導けない
  - **⚠ 「評価導出型だけは」と書かない（事実正確性レビュー）**。経験構成型も概念の在庫という感情の値以外のものを保持する。**書き分けるべきは種類ではなく役割**——評価導出型に固有なのは「進行中の感情エピソードを導くために必要な、出来事側のランタイム状態」であり、経験構成型の概念在庫は**長期の知識**であって単一のエピソードを導く要件ではない
- **経験構成型は、材料の層の上に蓄積の層が乗る**。概念は学習されるものなので、その在庫は書き換え可能でなければならない

**⚠ ch8 の領分を侵さない（最重要）**
`../state.md` は「4つは対等な選択肢ではなく**積み上げの関係**にある（OCC の感情状態はカテゴリー型の中身、Barrett の core affect は次元型の中身）」を **ch8 で回収する構造**と定めている。したがって ch3 では次を守る。
- **「4つは積み上げの関係にある」という一般的な結論を書かない**
- **「OCC の感情状態はカテゴリー型の中身」と書かない**
- 次元型と経験構成型の包含関係は **ch2 で既に公開済み**（心理構成主義を材料の層と構成の層に分けた説明）なので、ch3 で再度触れてよい。それ以外へ拡張しない
